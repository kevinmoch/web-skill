## 何时使用

当用户**笼统地**要「监控大屏」「新窗口打开的大屏」或投屏展示用的一页式项目监控视图时使用。
与 `agile-ops-dashboard`（会话内的敏捷运营报告）区分：本技能的交付物是**独立窗口**里的
深蓝主题大屏，适合投屏展示。

下列情况**一律改用 `authored-screen`**，本技能满足不了：

- 用户限定了数据范围（「当前页面的需求管理数据」「只看这个迭代」）——
  本技能的脚本一次把需求 / 迭代 / 缺陷 / 测试 / DORA 全取一遍，做不到按范围取；
- 用户指定了看哪些指标、怎么分区、什么配色；
- 用户看完后要求换分区、换配色或增删图表。

## 输入

- `projectId`（可选）：缺省取当前选中项目。

## 步骤

1. 调用 `agile-ops-screen__run`。脚本一次取数（需求 / 迭代 / 缺陷 / 测试套件 / DORA），
   填充模板并写出产物，会话里只渲染一个「查看监控大屏」按钮。
2. 该按钮是唯一入口：**不要**再调用 `render_ui` 或在会话里重造图表、按钮或链接，
   也不要提及下载或附件。回复一两句引导用户点击按钮即可，不要复述大屏上的数字。
