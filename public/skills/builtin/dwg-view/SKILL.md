## 何时使用

用户手上有 **DWG**，想看它、或想从它上面读点什么时使用。典型说法：

- 「打开这张图」「这份 dwg 里画的是什么」；
- 「这张图有几个布局 / 几个图层」；
- 「量一下这段墙有多长」「这个房间多大面积」；
- 「把这两张图放到一起看」「看看这版跟上版差在哪儿」——这时传两个 id。

**如果工具列表里没有 `view_dwg`**，说明当前宿主没有装配 DWG 读取能力。
直接告诉用户这个环境读不了 DWG，不要改用别的工具硬凑——
把 .dwg 当成文本去 `read_document` 只会得到一堆二进制垃圾。

## 图纸从哪来

三条通道，**同一个参数位**，不需要事先判断是哪一条：

- 用户**下载**过的文件：先列一下下载文件，把条目 id 填进来。
  下载列表会把 .dwg 标成「不可读取」——那说的是抽不出文本，**照样填进来**；
- 用户**附件**里的文件：直接用附件名；
- 当前**页面上的链接**：用 `read_linked_document` 拿到那份图纸的 id。

**两个 id 不必来自同一条通道。** 一个取自下载列表、另一个取自页面链接（或附件），
照样投到同一块画布上叠着看——查看器只认 id，不认它是怎么来的。
用户说「把我下载的这版跟网页上挂的那版比一比」时，直接两条通道各取一个就行。

## 步骤

1. 调 `view_dwg`，`files` 里放上面拿到的标识。**一次最多两个**：
   只看一张就传一个；用户明说要把两张放在一起时才传两个，**第一个是上层**。
   超过两个会整个报错，不会静默只开两张；要看更多就先问用户先看哪两张。
   查看器随即打开，每张图默认停在它自己的第一张非空布局上——
   工程师要看的通常是出图的那张纸，不是模型空间。
2. 工具回给你的**只有摘要**，每张图一条：实体总数、图层清单与各自的条数、
   有哪些视图、单位，以及画不出来的部分。**几何不进你的上下文**，这是刻意的。
3. 回复。规矩见下。

## 回复的规矩

**看图、量尺寸这些事由用户自己在查看器里做。** 你没有画面，也没有几何，
所以不要替用户「看」。你该做的是把入口交出去：左侧每张图一块面板，
顶上写着文件名，下面三页分别是视图、图层、属性；画面下方是量测工具栏
（距离 / 区域 / 坐标 / 角度 / 删除），可以设小数位，图纸没写单位时可以校准。

**两张图是叠着给人看的，不是让你去比对的。**
你拿不到任何一张图的几何，所以你**说不出**两张图之间改了什么。
不要给差异清单，不要猜「可能改了墙位」，也不要把两份摘要的图层名差集当成图上的差异——
图层名一样不代表画的一样。该做的是请用户自己看、自己量，并主动说明查看器上那几个控件干什么：

- 左下的「叠放」面板里，每一行是一层，可以勾选显示隐藏，也可以点名字选中它；
- 「换序」把上下两层对调，「染色」在两色区分与图纸原色之间切换；
- 两张图原点对不上时，开「对位」拖动选中层对齐，对歪了点「归零」。
  对位开着时画布归对位用，量测会自动收起；点任一个量测工具就退出对位，两者不会同时开着；
- 量测可以跨层吸附：一段的两头分属上下两层也量得出来。

**不要编造图上的内容。** 摘要里有图层名和条数，那是真的；
「东南角有一部疏散楼梯」这种话，除非摘要里真有，否则一个字都不能写。

**该转达的限制要转达：**

- 工具报了 ACIS 实体略去，就说明有一部分三维实体显示不了；
- 工具报了 `approximated`，就说明那部分画出来了但画得不准，读数别当准确值；
- 工具报了 `notDrawn`，就说明那部分压根没画，图上是缺的；
- 两张图的单位不一样时，跨层量出来的数没有可比性，要提醒用户。

这两类是两回事，不要合成一句「有些东西没显示」糊过去。

## 本技能没有脚本

目录里只有这一份 SKILL.md，没有 `scripts/`。这不是漏了，是做不到：

- 技能脚本跑在隔离沙箱里，**没有调用其他工具的出口**，够不到 `view_dwg`；
- 图纸几何刻意不进模型上下文，所以你也没法把它转交给脚本。

因此本技能的职责是**编排与纪律**——用哪个工具、怎么拿到文件、回复时守什么规矩，
而不是自己再造一套能力。解析、渲染、图层、量测都由查看器产出。
