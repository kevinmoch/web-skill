# 让它看你刚下载的那个文件（仅扩展版）

上一章讲的是助手做的东西存到你机器上；这一章方向相反：让助手读你机器上已有的文件。读自己的东西比存自己的东西敏感得多，所以这一章的重点不是它能读什么，而是每一次读取都要经过你点头。

> **仅扩展版**：本章讲的读取下载目录的能力只有扩展版有。网页版够不到你的下载目录，想让助手看一份本机文件，只能手动上传，见[附件、图片、语音与拍照](#/docs/attachments)。

## 你能做什么

- 直接说「看看我刚导出的那份表」，不用再打开文件夹把文件拖进对话
- 每一次列出清单、每一次读取文件，都先经过你点头
- 勾「不再询问」减少打断，随时可以在控制台撤销
- 读不了的格式在列清单时就会标出来，不用等点开才发现

## 这能干什么

你在业务系统里点了「导出 Excel」，文件落进下载目录。过去要让助手看这份表，得先找到它、再拖进对话框；现在直接说一句「看看我刚导出的那份」就行。省掉的是翻文件夹这一步。

## 它要问你两次

别默认「授权一次，之后随便读」——从开口到它读到内容，中间有两道授权卡，标题都是「需要授权」：

1. **想看目录里有什么，先弹一次卡**，问的是「允许助手查看你最近下载的文件列表吗？」。你点允许，它才列出最近下载的文件。
2. **想打开其中某一份，再弹一次**，问的是「允许助手读取你下载目录里的这份文件吗？」，卡上写明是哪个文件、多大。你确认后它才读。

为什么列个清单也要问？因为文件名本身就是信息：`离职证明.pdf`、`体检报告.pdf`——光把文件名列出来，就已经泄露了不该泄露的东西。第一道卡拦的是这个。

任何一张卡上点拒绝，就到此为止：它拿不到清单，也拿不到文件，只会如实告诉你这次没做成。

![M-18 一次读取要过几道门](/docs-assets/downloaded-files/zh/M-18.svg)

两道卡都要你点头；任何一道不允许，流程就此终止；读不了的格式在列清单时就已标出。

![列清单前弹出的第一道授权卡](/docs-assets/downloaded-files/zh/S-downloads-01.png)

第一道卡：你允许之前，它连目录里有什么都不知道。

![读取某个文件前弹出的第二道授权卡，卡上写明文件名与大小](/docs-assets/downloaded-files/zh/S-downloads-02.png)

第二道卡写明要读的是哪一份、多大，你确认后才读。

## 它看得到什么、看不到什么

清单里只有文件名、大小和下载完成时间，没有路径。助手全程拿不到文件在你磁盘上的位置——它拿到的是一个取件号，凭号取件，路径由浏览器扩展自己保管。所以它既说不出你的用户名，也说不出你把东西存在哪个盘。

它也不能主动去翻：只有你开口让它看，它才会去列目录。

## 「不再询问」记住的是什么

授权卡上有「不再询问」勾选项，标签把记住的范围直接写了出来：

- 列清单那张卡上：以后不再询问「列出下载目录」
- 读文件那张卡上：以后不再询问「读取下载的文件」

也就是说，记住的**不是这一个文件**，而是**整个下载目录上的这一类动作**。两类动作分别记忆：允许它列清单，不等于允许它开文件。

![授权卡上「不再询问」勾选项的特写](/docs-assets/downloaded-files/zh/S-downloads-03.png)

勾选前先看标签：它记住的是整个目录上的这类动作，不是眼前这一份。

想反悔：打开控制台，进 **连接 → 页面技能**，找到「已记住的页面操作」——下载授权和页面操作的已记住授权列在同一处，点**撤销**即可（见[连接](#/docs/console-connections)）。撤销立即生效，下一次它又会先问你。

![在控制台里撤销已记住的下载授权](/docs-assets/downloaded-files/zh/S-downloads-04.png)

已记住的授权可以逐条撤销，撤销后恢复逐次确认。

## 能读哪些格式

和你手动上传时能传的完全一样：

| 类型     | 能读的格式                         |
| -------- | ---------------------------------- |
| 图片     | png、jpeg、webp、gif               |
| 文本     | txt、md、csv、json、log、yaml、yml |
| 文件     | pdf                                |
| 文档正文 | docx、xlsx（Word、Excel）          |

Word 和 Excel 是在你的浏览器里读成文字再交给模型的，发出去的是文字，不是原文件——和手动上传走的是同一条路。

读不了的格式（比如 zip）在列清单时就已经标成读不了，不会等你点开了才报错。图片有一个例外：如果当前模型不认图，图片在列清单时就会被标出，并告诉你换个模型就行（见[选择模型](#/docs/models)），不会白发一趟再失败。

## 第一次用要先开个开关

这个能力出厂时是关着的，要用先开两道开关，缺一不可：

1. **控制台里的能力开关。** 打开控制台，进 **设置 → 沙箱与安全**，找到「下载的文件」一组，打开**允许读取下载的文件**。关着的时候助手根本不知道有这回事——它不会提出要看你的文件，而不是提了被拦住。

![在控制台打开「允许读取下载的文件」开关](/docs-assets/downloaded-files/zh/S-downloads-05.png)

2. **浏览器的文件访问开关。** 在地址栏输入 `chrome://extensions`，找到这个扩展，点「详细信息」，打开「允许访问文件网址」。这一步扩展自己打不开，必须你亲手开——这是浏览器在保护你，不是产品设计得麻烦。

![在 chrome://extensions 里打开「允许访问文件网址」开关](/docs-assets/downloaded-files/zh/S-downloads-06.png)

浏览器这一道开关只能由你亲手打开。

## 它知道你下载了东西吗

一种情况下知道：当它自己在页面上点了按钮、结果触发了下载（比如你让它去点「导出」），它会知道有下载发生了。但分寸要清楚：

- **它只知道「发生了」，不知道文件叫什么。** 想知道名字，还得走前面那两道卡。
- **只统计它自己那次操作引起的下载。** 你自己在旁边下载别的东西，它看不见。

换句话说，它没有在盯着你的下载目录。而且它对文件只读：不能改名、不能删除、不能往里写东西。

## 网页版与扩展版的差别

本章的全部能力仅扩展版有。网页版读不到你的下载目录；要让助手看一份本机文件，只能手动上传——两种走法能处理的格式完全一致。

## 出问题了怎么办

- **提示去 `chrome://extensions` 开开关。** 浏览器的文件访问权限还没给，按上一节开好，然后重试。
- **提示文件打不开，可能已被移动或删除。** 文件真的不在原处了，找到它或重新下载后再试。这时不用再去动那个权限开关——开关没有问题，动了也是白忙。
- **提示这个格式读不了。** 类型不在上面四类之内，把它转成 pdf 或文本格式再试。
- **提示当前模型看不了图片。** 换一个支持图片的模型，见[选择模型](#/docs/models)。
- **助手让你把文件手动传给它，像不知道有这个功能一样。** 多半是能力开关没开：到 设置 → 沙箱与安全 打开**允许读取下载的文件**，再说一次。
