# 会画画的回答：生成式界面

一批数据、一组对比、一张要填的表——只用文字表达反而绕弯，所以助手有时会把回答直接画成界面：表格、图表、表单、看板，或是一个能在新窗口打开的文档。这叫**生成式界面**：回答不只是文字，还是能看、能填、能点的界面。

## 你能做什么

- 认出回答里的五种形态：表格、图表、表单、看板、文档
- 在表格里排序、拖列宽；在表单里填写并提交
- 用字段下方的「建议：」，点「使用」把建议值填进去
- 点「打开文档」，在新窗口看大屏、公文或幻灯片
- 看懂两条限制提示：只读记录、条目组只显示第一项

## 不只是文字

大多数回答是文字。但当内容本身是「一批数据」或「一张要填的表」时，助手会直接把回答画成界面，不用你做任何设置。同一个问题，它这次可能用文字、下次可能用表格，取决于哪种更清楚。界面的配色跟着你的深浅主题自动变化，切主题后不用重新提问。

![M-09 一个回答可以长成什么样](/docs-assets/generative-ui/M-09.svg)

一个回答有六种长相：表单是请你填的，文档要你点按钮打开，其余主要用来看。

## 你会遇到哪几种

### 表格

清单类回答通常直接排成表格。点列头可以排序，拖动列的边缘可以调列宽。数据多时，表格可能先出现几行、随后逐行补齐——它在边生成边画，不是卡住。

![表格型回答：点列头排序，拖列缘调列宽](/docs-assets/generative-ui/zh/S-genui-01-table.png)

清单类回答排成可排序的表格。示例运行结果，你的实际输出会有所不同。

### 图表

趋势、占比、对比类回答会给图表，旁边常配几张指标卡：一个大数字加一个名称。在 Demo 里发 `生成当前项目的敏捷运营报告，覆盖迭代健康、需求分布、缺陷热点和测试质量`，就能看到一份指标卡、图表、表格混排的报告式回答。

![图表型回答，旁边配指标卡](/docs-assets/generative-ui/zh/S-genui-02-chart.png)

图表与指标卡可以混排。示例运行结果，你的实际输出会有所不同。

### 表单

助手需要你一次补好几项信息时，除了弹固定的卡片（见[助手向你要东西：六种交互卡](#/docs/interactions)），也可能把表单直接画进回答：文本框、下拉项、日期、勾选，填完点提交。可以重复填一组的条目带「添加」「移除」按钮。某个下拉显示「该字段没有可选项。」时，是选项列表为空，不是坏了——改用文字直接告诉它即可。

![表单型回答：字段可直接填写，条目组可增删](/docs-assets/generative-ui/zh/S-genui-03-form.png)

表单画在回答里，空字段下方有时会带一行建议值，见下文。示例运行结果，你的实际输出会有所不同。

### 看板

状态分布、进度总览类回答可能给一面看板：卡片按列排开，哪一列堆得多一眼可见。看板是摆给你看的，卡片不支持拖动。

![看板型回答：卡片按列排开](/docs-assets/generative-ui/zh/S-genui-04-kanban.png)

看板把一堆状态分区摆开，只供查看。示例运行结果，你的实际输出会有所不同。

### 文档

大屏、公文、幻灯片这类整页作品，在对话里是一张带「打开文档」按钮的卡片；点它，作品在新窗口打开。在 Demo 里发 `在新窗口打开当前项目的交付监控大屏：迭代进度、缺陷分布、测试质量与 DORA 指标一屏总览` 就能得到一个。打开后怎么翻页、打印、导出，见[产物：大屏、公文、幻灯片与打印](#/docs/artifacts)。

![文档型回答：一张带「打开文档」按钮的卡片](/docs-assets/generative-ui/zh/S-genui-05-document.png)

点「打开文档」，整页作品在新窗口打开。

## 怎么和它交互

表格、图表、看板用来看：排序、翻页（「上一页」「下一页」）。表单用来填：提交后回答接着你的输入继续——结果图表的标题里可能就有你刚选的那个值。

表单里藏着一个少被发现的省事入口：**建议值**。字段还空着时，下方可能出现一行小字：开头是「建议：」，后面跟一个值，有时带括号里的依据，行尾是「使用」按钮。点「使用」，值就填进字段；不点就不填——它不会自动写入，觉得不对忽略即可。字段里已有内容时，这行不会出现。

![表单字段下方的建议值行：「建议：」开头，行尾是「使用」按钮](/docs-assets/generative-ui/zh/S-genui-08-suggestion.png)

建议值行的真实样貌。示例运行结果，你的实际输出会有所不同。

## 保存下来的记录不能再操作

界面型回答会随会话保存在本机。刚生成的这一轮里它是活的：能填、能点、能提交。等你过后翻回来（刷新、重开页面、切换会话再回来），界面还在原处、内容不变，但不能再操作，下方多出一行：「这是已保存的记录，其中的操作已不可用。」

数据没有丢——界面成了一份保存下来的记录。想再操作，重新发一句话，让它再画一张。

![历史会话里的界面卡片，下方显示「这是已保存的记录，其中的操作已不可用。」](/docs-assets/generative-ui/zh/S-genui-06-readonly.png)

翻回来再看时按钮已不可用，提示贴在界面下方。

## 有些内容只显示第一项

表单里可重复添加的条目组，在个别呈现方式下只显示第一组，并有一行提示：「当前渲染档只显示重复组的第一项。」第一组仍可正常填写、提交；其余组没有丢，只是这种呈现方式画不出来。呈现方式由你所在的系统在 Console 的「设置 → 生成式 UI」里选择（见[设置](#/docs/console-settings)），换一种就能看全。个别呈现方式下这句提示显示为英文「This renderer shows only the first item of a repeatable group.」，是同一条提示。

![条目组只显示第一组，下方提示「当前渲染档只显示重复组的第一项。」](/docs-assets/generative-ui/zh/S-genui-07-array-first-item.png)

只显示第一组是呈现方式的限制，不是数据丢了。

## 网页版与扩展版的差别

生成式界面本身两者一致：五种形态、建议值、两条限制提示，在两个版本里长得一样、行为一样。「文档」形态的打开方式也一致：点「打开文档」后，两种形态都会先弹一张标题为「请确认」的确认卡，你同意后才开窗。差别只在窗口的承载方式：网页版打开的是所在网站自己的查看器页面，扩展版的窗口由扩展替你开启。确认卡的细节见[产物：大屏、公文、幻灯片与打印](#/docs/artifacts)。

## 出问题了怎么办

- **翻历史会话时，界面上的按钮点不动。** 正常，那是已保存的记录（「这是已保存的记录，其中的操作已不可用。」）。想重新操作就发新消息。
- **条目组好像少了几条。** 有「当前渲染档只显示重复组的第一项。」这行提示，就是显示限制，数据没丢，换一种呈现方式即可看全。
- **整块界面是一块标着「预览」的数据预览，不能交互。** 你所在的系统选了一种仍在预览阶段的呈现方式，换一档即可。
- **旧会话里有的界面只剩一行「旧版本生成的界面已不再渲染。」** 早期版本生成的界面无法在新版本里呈现；内容还在文字回答里，需要界面就重新问一次。
- **这次回答只有文字，以前却会画界面。** 你所在的系统可能在设置里关掉了生成式界面的开关。开关只管「助手主动画界面」：技能（让助手会干某件事的说明书）产出的界面和六种交互卡照常出现。细节见[设置](#/docs/console-settings)。
