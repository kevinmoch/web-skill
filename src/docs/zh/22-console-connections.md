# 连接

助手能回答、能干活，靠的是两类源头：用哪个模型思考，能调用哪些工具——工具就是它能执行的一个具体动作，比如「读取需求列表」「跳转到某个页面」。控制台 **连接** 组的四个页面管的就是这些源头。日常对话用不到这里；要填模型的地址和密钥、接上更多工具来源、或查「它为什么会/不会做这件事」时才来。

## 你能做什么

- 在 **大模型** 页添加模型、测试连接、设定默认项
- 在 **MCP 端点** 页接上外部的工具服务，看连接状态和工具清单
- 在 **WebMCP 工具** 页开关当前网页自己提供的工具
- 在 **页面技能** 页看当前页面给了助手哪些临时技能、它能读页面的哪块区域
- 逐个启停单个工具，以及撤销勾过「以后不再询问」的页面操作授权

## 四个页面各管什么

助手一次回答用到的能力可能来自四个地方：技能库里装好的技能（打包好的「做某件事的说明书」）、你所在系统提供的页面工具、网页自己报出来的工具、网络上别的工具服务。加上「用哪个模型」，正是这个组四个页面管的事。

![M-23 工具从哪儿来：技能、页面工具、网页自带的工具、远程工具服务四个来源汇入助手可用的能力](/docs-assets/console-connections/M-23.svg)

四个来源汇成同一份能力清单；哪一路没接上，对应的能力就不在清单里。

### 大模型（LLM）

**做什么用**：助手能用的模型都在这个列表里。对话里可以按会话换（见[选择模型](#/docs/models)），没换的用默认项；一个都没添加时回退到内置演示模型——能对话，但不连真实模型服务，只是演示。

**你在这里可以**：

- 点 **添加模型**，填 **显示名称**、**供应商**、**模型** 名；供应商有 OpenAI 兼容 / Anthropic / Google / Chrome 内置 四种
- 服务方给了独立地址就填 **Base URL（可选）**，密钥填进 **API key**——保存后列表里不显示明文
- 点 **测试连接** 真实探测一次：端点可达 还是 端点不可达或未配置、是否 支持流式，都写明原因
- 用 **设为默认** 指定新会话的默认模型；删除要再确认一次

![大模型页：每条模型显示名称、供应商与模型名，默认项带标记](/docs-assets/console-connections/zh/S-console-conn-01-models.png)

默认项带 默认 标记，密钥不明文显示。

**常见用法**：从模型服务方拿到地址和密钥后——添加模型，选供应商，填 Base URL 与 API key，点 测试连接 看到 端点可达，保存后 设为默认。第一条模型自动成为默认项；删掉默认项时，默认自动落到剩下的第一条。

两个开关的后果要知道：关掉 **支持工具调用**，这个模型只剩纯聊天，不调技能也不读页面；关掉 **支持图片输入**，就不能给它发图片。**Chrome 内置** 档在本机运行、不用填密钥，但不支持工具调用。

### MCP 端点（MCP Endpoints）

**做什么用**：把你所在系统之外的工具服务接进来。MCP 是一种通用的接入方式，一个端点就是一个工具服务的地址；连没连上、提供了哪些工具，都在这一页。

**你在这里可以**：

- 点 **添加端点**，填 **名称**、**URL**、**传输协议**，需要时加 **请求头**
- 看每个端点的状态：已连接 / 连接中 / 失败 / 不可用；失败写明原因——主机名拼错、服务没启动、凭据被拒绝各有说法
- 点 **测试** 跑一次真实往返并报告耗时，失败给出可定位的 **失败详情**
- 用 **重连** / **禁用** / **移除** 管理端点；移除要再确认，移除后它的工具立即不可用。添加与移除都会记进[治理与复核](#/docs/console-governance) 的审计日志
- 有的服务要先登录授权：添加时打开 **使用 OAuth**；之后行上显示 未授权 / 已授权 / 授权已过期，过期了点 **授权** 重新登录
- 在下方的 **端点注册表** 看所有已连接端点提供的工具，点工具名看它要求传哪些参数

![MCP 端点页：端点列表实时显示连接状态与工具数，失败原因写在状态旁](/docs-assets/console-connections/zh/S-console-conn-02-mcp.png)

状态、工具数、出网策略标记都在行内。

**常见用法**：Demo 里自带一个 `agile-page` 端点——你所在的系统（Agile Studio）就是通过它把工具提供给助手的，共 10 个。其中 8 个管业务：查需求、查迭代、查缺陷、查测试套件、取指标、列项目、切页面、取填表建议；另外 2 个（`list_skill_files`、`write_skill_file`）管技能文件本身，让助手能读懂、修改你装好的技能——[把这次做过的事变成一个技能](#/docs/case-skill-lifecycle)走的就是它们。对话里说 `帮我打开缺陷管理页面`，走的是其中的切页面工具。

![端点注册表里 Demo 的页面端点与它的 10 个工具](/docs-assets/console-connections/zh/S-console-conn-05-agile-page.png)

每个工具都能单独启停。不想让助手自己切页面，把那一个工具拨到 已禁用 就行，同端点其他工具照常。

![单个工具的三档启停：已启用 / 按需启用 / 已禁用；端点被禁用时它的工具标 端点已禁用](/docs-assets/console-connections/zh/S-console-conn-06-tool-toggle.png)

> **注意**：添加端点时，**允许该端点使用明文 http** 与 **允许该端点访问内网与环回地址** 默认都是关的，确认过再勾；且只能在 设置 › 沙箱与安全 已放行的范围内打开——全局禁止时这里勾不上。MCP 服务有两种：有网络地址的，和跑在你电脑上靠命令行启动的；浏览器里只接得了前一种。

### WebMCP 工具（WebMCP Tools）

**做什么用**：看你正在看的这个网页自己提供了哪些工具。WebMCP 是浏览器里的一条标准通道：网页经它把工具直接报给助手，你所在的系统不用额外接线。页面带 实验性 标记，能力可能随浏览器版本变化。

**你在这里可以**：

- 按来源分组：页面主体和内嵌的页面区域各算一个来源，每组标着三态之一——不支持 / 支持但未启用 / 已启用
- 用 **启用 WebMCP** 打开某个来源，关掉它不连坐其他来源
- 对来源里的每个工具再逐个选 已启用 / 按需启用 / 已禁用
- 带 **不可信内容** 徽章的工具返回的是网页自己的内容，助手把它当参考资料，不当指令照做

![WebMCP 工具页：按来源分组，每组标着三态之一，工具逐个启停](/docs-assets/console-connections/zh/S-console-conn-03-webmcp.png)

来源名、状态徽章、逐工具启停都在各自的分组里。

**常见用法**：Demo 就声明了一组这样的工具：当前视图、项目、需求、迭代、缺陷、测试、指标，共 7 个。对扩展版这条通道尤其重要——助手不在页面里，网页报出来的工具是它拿到页面数据的主要来路。浏览器太旧时这页显示「当前浏览器/环境不支持 WebMCP。」——这是浏览器的事，不是你的系统坏了。

### 页面技能（Page Skills）

**做什么用**：看当前页面临时给了助手哪些技能。这类技能不装进技能库：离开或关闭这个页面，它就从目录里消失——界面原文是「随页面生成或销毁」。长期驻留的技能在[技能管理](#/docs/console-skills) 的技能库。这一页还管两件事：助手能读页面的哪块区域，以及你记住过的授权。

**你在这里可以**：

- **页面声明的临时技能** 区块列出当前页面给的技能，每条带 来源 与 渠道 两枚徽章；点行尾 查看技能契约 读完整内容
- **页面只读感知** 区块核对：状态（已启用 / 未启用）、**可感知区域**、**排除区域**；页面还可能单独声明 **可操作范围**——能读不等于能操作
- **页面图像抓取** 默认关闭，打开后可读区域内的图片随读取一并发给模型服务方；张数与大小上限去 设置 › 智能体运行时 改
- **最近感知记录** 逐条列出每次读取的时间、区域与节点数
- 在 **已记住的页面操作** 区块撤销已记住的授权——见下节

![页面技能页：临时技能、感知范围、已记住的授权三块从上到下](/docs-assets/console-connections/zh/S-console-conn-04-page-skills.png)

感知区块是只读的，唯一的开关是 页面图像抓取。

**常见用法**：在 Demo 里，这一页列着各屏声明的临时技能，徽章标明它是哪一屏声明的——比如需求管理屏上有一个检查需求状态与迭代阶段是否自洽的技能，迭代管理屏上有一个判断迭代能否按时收尾的技能。你站在哪一屏，助手手头就是那一屏的技能；切了屏，上一屏的就失效——这不是丢了，是它随页面生灭。感知细节见[让助手读当前页面](#/docs/page-perception)。

### 撤销已记住的授权

对话里勾过「以后不再询问」的页面操作，都列在 **页面技能** 页的 **已记住的页面操作** 区块——界面原文：「选择了“以后不再询问”的操作。撤销后会恢复逐次确认。」条目按记住的范围分组，逐条点 **撤销**，或点 **全部撤销** 清掉一整组；撤销立刻生效，不用刷新页面，下一次同类操作会重新弹卡问你。一条都没记住时，区块里写的是「没有记住任何授权，每次页面操作仍会先问。」授权卡本身的规则见[让助手操作页面](#/docs/page-actions)；扩展版的下载文件授权也在同一处撤销，见[让它看你刚下载的那个文件](#/docs/downloaded-files)。

## 网页版与扩展版的差别

|  | 网页版 | 扩展版 |
| --- | --- | --- |
| 这四个页面在哪 | 你所在网站内部的管理页（Demo 里点对话头部的 **设置**） | 扩展的选项页 |
| 大模型页 | 一致 | 一致 |
| MCP 端点页 | 可以手动添加、移除远程工具服务 | 列出的是当前绑定网页自己提供的端点，随换页清空；不支持手动添加 |
| 网页工具的覆盖面 | 只有你所在的这个网站 | 任意网页：页面一行不改，助手也能发现它的端点、临时技能与 WebMCP 工具 |

## 出问题了怎么办

- **端点状态显示 失败。** 原因写在状态旁：主机名拼错、服务没启动、凭据被拒绝各有说法。改好后点 **重连**；不确定通不通就点 **测试**。
- **助手说某个工具不可用，或压根不提它。** 到 **MCP 端点** 页的 **端点注册表** 或 **WebMCP 工具** 页查那个工具：是不是被拨成了 已禁用，或者它所属的端点 / 来源被整个停用了。
- **助手突然只会聊天，不调技能也不读页面。** 到 **大模型** 页看当前模型的 **支持工具调用** 是不是被关了——关掉它助手就只剩纯对话。模型能力标记的含义见[选择模型](#/docs/models)。
- **WebMCP 工具 页显示 当前浏览器/环境不支持 WebMCP。** 浏览器太旧或没开对应的实验开关。这不影响系统经自己的通道提供的工具，只是这条浏览器通道用不了。
- **昨天还在的临时技能今天没了。** 它随页面生灭：换页、关标签页都会让它消失，技能库里也找不到——这是设计如此，不是丢了。
