# 附件、图片、语音与拍照

除了打字，你还可以把文件和图片挂在消息上一起发，或者干脆用说的、用摄像头拍一张。这一章讲能传什么、传进去之后会发生什么，以及传不了的时候怎么办。

## 你能做什么

- 给消息挂附件：图片、文本、PDF，也包括 Word 和 Excel
- 用**语音输入**把说的话转成文字，落进输入框再发
- 用**拍照**调用摄像头拍一张，作为附件放进输入框

## 你能传哪些文件

点输入框下方的**添加附件**选择文件，也可以把文件直接拖进输入区。挂上去的附件显示为一个小片，带文件名、大小和一个类型标签。类型标签有四种，各自接受这些格式：

| 类型标签 | 你可以传 |
| --- | --- |
| 图片 | png、jpeg、webp、gif |
| 文本 | txt、md、csv、json、log、yaml、yml |
| 文件 | pdf |
| 文档正文 | docx、xlsx |

**Word（docx）和 Excel（xlsx）能直接传**，它们归在「文档正文」这一类。不在表里的格式（比如 zip）传不了。

![输入框里挂着多个附件小片，各自带类型标签](/docs-assets/attachments/zh/S-attachments-01-chips.png)

附件小片上有文件名、大小和类型标签，发出去之前随时可以移除。

![挂着一份 xlsx 的输入框，类型标签显示「文档正文」](/docs-assets/attachments/zh/S-attachments-07-xlsx-doc-text.png)

Excel 传上去后，类型标签是「文档正文」而不是「文件」。

## 传进去之后会发生什么

四类附件不是同一种发法，差别你能观察到：

| 类型 | 发出去的是什么 | 你要知道 |
| --- | --- | --- |
| 图片 | 图片本身 | 太大的会先压缩；每条消息有张数上限 |
| 文本 | 文件里的文字 | 超过 32K 字符的部分会被截断 |
| 文件（pdf） | 整份文件 | 需要模型支持文档输入 |
| 文档正文（docx/xlsx） | 从文件里读出的文字 | 原文件不会整份发出去 |

最后一类值得多说一句：Word 和 Excel 是**在你自己的浏览器里读成文字**再发的，发出去的只是读出来的正文文字——文档里的图片和排版不在其中——原文件始终不离开你的机器。各类内容发给谁、你能控制什么，见[隐私与数据去向](#/docs/privacy)。

![M-10 一份文件进入对话的路径](/docs-assets/attachments/M-10.svg)

不管文件从哪来——选文件、粘贴、拍照——都先成为输入框里的附件，再按类型走不同的路；你点**发送**之后才真的发出去。

32K 字符是什么概念：日常的会议记录、需求摘要远没有这么多；一份攒了几个月的完整日志很容易超过。超长的文件不必整份传，截取相关的那几段再传更有效。

## 图片会被压缩

图片太大时会先压缩再发。压缩后附件小片上会多一行标注：「已压缩 {from} → {to}」，压前压后的大小都看得见。压缩的只是发出去的那份副本，你机器上的原文件不动。实在压不到上限以内，会被明确拒收并说明原因，不会静默丢弃。

![附件小片上的压缩提示「已压缩 …」](/docs-assets/attachments/zh/S-attachments-02-compressed.png)

压缩是发送前的自动步骤，不需要你做任何事。

每条消息能带的图片有张数上限。一次挂多了，超出的那些**不会跟着发出去**，消息流里会明确列出：「每条消息最多发送 {limit} 张图片。未发送：{names}」——哪几张没发，名字都在。想发就把它们分到下一条消息。

![超出张数上限的提示，列出了未发送的文件名](/docs-assets/attachments/zh/S-attachments-08-images-dropped.png)

单张大小和每条张数这两个上限都在「设置 → 多模态」里，由你所在的系统调整，见[设置](#/docs/console-settings)。

## 用说的代替打字

1. 点输入框下方的**语音输入**。第一次用时浏览器会申请麦克风权限，允许后进入录音，界面上显示「录音中」。
2. 对着麦克风把话说完，点**停止语音输入**。
3. 识别出的文字会填进输入框——识别在浏览器本地进行。先读一遍、改好，再点**发送**：它替你把字打好，发不发、发什么仍由你定。

![语音输入录音中，按钮变为「停止语音输入」](/docs-assets/attachments/zh/S-attachments-03-dictating.png)

录音中再点一次同一按钮就结束，文字随即落进输入框。

提示里都说清了原因和去处：

- 「浏览器拒绝了麦克风。请在站点权限设置里允许麦克风后重试。」——到浏览器的站点权限设置里允许麦克风，再点一次。
- 「语音输入意外中断。可以再试一次，或直接打字。」
- 「当前浏览器不支持语音识别。」——换一个支持的浏览器，或直接打字。

不管撞上哪一种，打字输入都不受影响。

## 用摄像头拍一张

1. 点输入框下方的**拍照**，弹出取景对话框。
2. 对准要拍的东西——一张纸、一块屏幕、一个报错弹窗——点快门**拍照**，取景框随即关闭。
3. 照片作为附件小片挂进输入框。对话框里写得很清楚：「拍好的照片会作为附件放进输入框，你点发送才会发出去。」检查缩略图，配上你的问题，再点**发送**。

![拍照对话框：取景画面与快门](/docs-assets/attachments/zh/S-attachments-04-camera.png)

拍完只是挂进输入框，不点发送就不会发出去。

拍照按钮灰掉时，悬停它会写明缺的是哪一道前提（图片通道没开、当前模型不收图等），照提示补齐即可。摄像头的失败提示与麦克风一一对应：

- 「浏览器拒绝了摄像头。请在站点权限设置里允许摄像头后重试。」
- 「没能拍下这张照片。可以再试一次，或改为直接添加图片文件。」

## 什么时候传不了图

传图片被拦下时，提示只有两种，各有各的解法：

1. **「图片已在「设置 → 多模态」中关闭」。** 图片通道默认是关的（Demo 里默认打开），因为开启后选中的图片会上传给你配置的模型服务商。到设置里打开**图片附件**即可，见[设置](#/docs/console-settings)。
2. **「当前模型不接受图片」。** 你正在用的模型不认图。换一个模型能力标记里有「可传图片」的模型，见[选择模型](#/docs/models)。

![「当前模型不接受图片」的提示](/docs-assets/attachments/zh/S-attachments-05-model-no-images.png)

提示会写明是哪一种原因，照它指的方向走即可。

PDF 有对应的情况：它整份发给模型，模型那边拒绝时，错误卡里会附带一句说明（以英文显示）——这轮带了文档，当前模型可能不接受文档输入。换一个支持文档的模型，或把内容另存为 Word、纯文本再发。

## 网页版与扩展版的差别

附件的四类、压缩、截断、张数上限，两者一致；语音输入和拍照两个版本也都有。差别在第一次授权：

> **仅扩展版**：扩展版住在浏览器侧栏里，侧栏没有地方弹浏览器的权限框。第一次点**语音输入**或**拍照**时，它会自动打开一个普通标签页请你授权，侧栏里提示：「麦克风需要在普通标签页里授权一次。请在那里完成授权，再回到这里重试。」摄像头同理：「摄像头需要在普通标签页里授权一次。请在那里完成授权，再回到这里重试。」在那个标签页里点允许，回到侧栏再点一次就能用。授权只需一次，之后直接用。

![扩展版提示麦克风或摄像头需要先在普通标签页里授权一次](/docs-assets/attachments/zh/S-attachments-06-handoff.png)

网页版没有这一步：浏览器直接在当前页面弹权限框，允许即用。

## 出问题了怎么办

- **传图片被拒，提示图片已关闭。** 到「设置 → 多模态」打开**图片附件**（见[设置](#/docs/console-settings)）；如果你用的是 Demo，它默认就是开的。
- **提示「当前模型不接受图片」。** 换一个能力标记里有「可传图片」的模型，见[选择模型](#/docs/models)。拍照按钮是灰的，通常也是同一个原因。
- **传了一份长文本，回答却像没看完。** 多半超过 32K 字符被截断了，截取相关的段落再传。
- **语音或拍照提示被浏览器拒绝。** 按提示到浏览器的站点权限设置里允许麦克风或摄像头再重试；扩展版则先去自动打开的那个普通标签页里完成授权。
- **PDF 发出去后模型报错。** 当前模型可能不接受文档输入：换模型，或把内容转成 Word、纯文本再发。
