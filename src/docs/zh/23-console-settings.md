# 设置

控制台「设置」组的八个页面管着助手的脾气：它一次最多干多久、技能脚本有多大权限、回答画成什么样、它记不记你、界面用什么语言。本章按侧栏顺序逐页讲，每页只说一件事——改了它，你会看到什么不同。所有页面都能在 [Demo](/demo) 里实际对照：打开控制台（Demo 里点对话头部的**设置**，或左侧导航的技能中心），侧栏最下面一组就是**设置**。

## 你能做什么

- 调整助手一次运行的轮次与时长上限，触顶时知道去哪改
- 决定技能脚本能不能联网、能用哪些能力、哪些要逐次问你
- 更换生成式界面的渲染框架，预览五种交互卡片
- 自己往欢迎页加一条一点即发的快捷指令
- 管住技能来源：信任哪些签名、没签名的技能怎么办
- 查看、删除、导出助手记住的画像；切换主题与语言；导出诊断信息

## 八个设置页

![M-24 设置项影响什么：左侧是八个设置页，右侧是它们各自影响的行为](/docs-assets/console-settings/M-24.svg)

想改某个行为但不知道去哪页时，从这张图反查：右边找到那个行为，左边就是该去的页。

八页的共同规矩先说清：改动**即时保存**，不用点「保存」；对**下一次运行**生效，不打断正在进行的那次；每页底部都有**恢复默认**，点它会先弹确认「恢复本页默认设置？」，确认后只还原本页。

### 智能体运行时（Agent Runtime）

**做什么用**：助手最多干多久、卡住了怎么办、结果以什么形式给你。

**你在这里可以**：

先在**智能体循环**一节调四个上限（默认值均来自出厂设置）：

| 设置项 | 管什么 | 默认值 |
| --- | --- | --- |
| 最大轮次 | 给出最终回答前，助手思考加执行最多多少个来回 | 1000 |
| 总超时（秒） | 一次运行的总时长；等你回答卡片的时间不计入 | 3600 |
| 工具超时（秒） | 一次工具调用多久算卡死 | 600 |
| 历史消息上限 | 每一轮回放给模型的历史消息条数 | 1000 |

触顶后运行会停下，提示里写明是哪个上限、当前值多少，错误卡上有按钮直接跳到这一页，终止原因的对照见[看懂助手在做什么](#/docs/transparency)。调大轮次与时长会更费 token；想先看看触顶长什么样，可以把上限调小试一次，**试完记得调回来或点「恢复默认」**——它影响的是你之后的每一次运行。

- 在**交互**一节决定：缺参数时**询问用户**还是**交由大模型补全**；需确认的操作**必须确认**还是**自动批准**；**交互超时（秒）**管卡片等你多久——默认 300 秒，超时未答运行就以「表单未及时提交」结束。
- 在**智能体能力**一节逐项开关：**待办清单**、**生成式 UI**、**技能自动生成**（把对话存成技能的入口，出厂默认关、Demo 默认开，效果见[技能：让助手会干专业活](#/docs/skills-usage)）、**委派子任务**（它把某一步交给另一个技能串行做完再继续，一句话可能展开成多次运行）。当前模型不支持工具时这四项置灰，页面上会写明原因。
- 在**多模态**一节决定图片能不能发给模型：**图片附件**、**页面图像抓取**出厂默认都关（Demo 默认开），开了之后对话里会看到抓图计数，见[让助手读当前页面](#/docs/page-perception)。
- 其余散项：**失败隔离阈值**——技能连续失败这么多次就自动隔离（默认 5 次，成功一次就清零）；回答是否逐字流出（**流式响应**）、末尾是否带**渲染结果块**；三个体积上限（工具结果、文档、抽取文本，单位 KB）——超限会拒绝而不是截断，错误里写明实际大小、上限和去哪改；**温度（可选）**留空则用模型厂商默认值。**生命周期钩子**一节由你所在的系统决定：系统一个钩子都没注册时，这一节显示空态「未注册任何生命周期钩子。」；系统没接这个入口时，整节不出现。

![智能体运行时页：上限、交互、智能体能力、多模态等各节](/docs-assets/console-settings/zh/S-console-set-01-runtime.png)

**常见用法**：大任务老是「达到轮次上限」——先把任务拆小、分几次说；确实需要长跑，再把**最大轮次**调大。

### 沙箱与安全（Sandbox & Security）

**做什么用**：技能脚本跑在多严的隔离里、能不能联网、哪些能力要一事一议。沙箱是技能脚本运行的隔离环境：跑在里面的代码碰不到你的页面和数据，只能用这里放行的能力——数据去向的总账见[隐私与数据去向](#/docs/privacy)。

**你在这里可以**：

- 选技能脚本的运行方式：**自动**（默认，自动挑可用的最强隔离）、**Blob Worker**、**Iframe 沙箱**（浏览器里最强的隔离）。没有特殊原因不用动。
- 定**网络策略**：**全部拒绝**（默认）/ **全部允许** / **白名单**。技能脚本想联网而被拦时，失败原因会写明是策略拒绝，不是网络不通。
- 在**出站 URL 策略**里放开明文 http 或内网地址（默认都关），并用**试跑 URL** 当场验证某个地址放不放行——它和真实安装走的是同一条判定。
- 按需开启（出厂默认都关）：**技能数据源**（按名字登记允许技能取数的地址，取数结果默认限 1000 KB）、**TypeScript 支持**、**允许打开文档**、**允许技能脚本读上传的文件**（每次读仍会先问你；单个文件默认限 20 MB，超出拒绝而不是截断。Demo 把这一项默认打开了）。**允许读取下载的文件**对应扩展版的能力，见文末的形态差异。
- 给五项能力各定一档：**开**（直接做）/ **需要审批**（弹卡问你）/ **关**（直接拒绝）——读取参考资料、读取素材文件、写入产物、确认出厂默认开，**读取数据源**默认关（Demo 默认开）。**审批粒度**决定一次批准管多久：**每次运行一次**（默认）或**每次调用**。

![沙箱与安全页：运行方式、网络策略与逐项能力开关](/docs-assets/console-settings/zh/S-console-set-02-sandbox.png)

**常见用法**：技能的联网请求被策略拦下——把它的地址加进**白名单**，用**试跑 URL** 确认放行后再回对话重跑一次。

### 生成式 UI（Generative UI）

**做什么用**：助手生成的表格、图表、表单由哪个渲染框架画出来，以及它能选用哪些排版预设。这是全书唯一会出现渲染框架名的地方——界面上就这么写。

**你在这里可以**：

- 在四个框架里选一个：**Native（React）**（默认，随产品自带）、**A2UI**、**OpenUI**、**Vercel AI SDK**。**A2UI** 与 **OpenUI** 需要你所在的系统先装上对应部件，没装的会置灰并写明缺什么；**Vercel AI SDK** 带「预览」标记，是数据预览档，不涉及安装。切换当场生效，回对话就能看到呈现差别——比如重复组的显示方式会随框架变化，见[会画画的回答：生成式界面](#/docs/generative-ui)。
- 在**交互卡片**预览区直接看五种卡片（提问、确认、表单、选择、授权）在当前框架、当前主题下的样子。
- 在**场景预设**里勾选助手可选用哪些排版预设；智能体运行时页的**生成式 UI**总开关关掉时，这里全部置灰。
- 翻看 **AI 组件目录**：助手能画的组件逐行列出，附「什么时候用」。

![生成式 UI 设置页：四个渲染框架与交互卡片预览](/docs-assets/console-settings/zh/S-console-set-03-genui.png)

**常见用法**：觉得卡片样式不对——先到这页的预览区确认这就是当前框架的呈现，再决定要不要换。

### 快捷指令（Quick Prompts）

**做什么用**：对话欢迎页上那些一点即发的指令卡片，在这里增删改。

**你在这里可以**：

1. 点**新增快捷指令**。
2. 填**中文文案**和**英文文案**（至少填一种；没填的语言会借用已填的那种），可再从内置图标里挑一个。
3. 点**保存**。回到对话新开一个会话，欢迎页上就有它，点卡片发出的就是你填的那段原文。

![新增快捷指令的编辑对话框](/docs-assets/console-settings/zh/S-console-set-09-add-prompt.png)

- 每条指令可**编辑**、**删除**（有确认，删掉只影响欢迎页，已有会话不受影响）。写法有讲究：不留待填空、不写死编号，点了就能跑——Demo 自带的一条可作范本：`分析当前迭代的燃尽情况，判断能否按时收尾，说明依据和风险`。
- **对话里展示的条数**默认 8 条、最多 20 条；加超了欢迎页只显示前几条，这页会提示。
- **恢复宿主默认**：清空你改过的清单，让你所在的系统下次重新放上它自己的指令——有确认，你在这里编辑过的指令会全部丢失。

![快捷指令页：指令清单与展示条数](/docs-assets/console-settings/zh/S-console-set-04-prompts.png)

**常见用法**：把每周都要问的那句话加成指令，比如「用周报模板输出本迭代的进展简报」，以后点一下就发出去。

### 信任与签名（Trust & Signing）

**做什么用**：信任哪些技能签名、没签名的技能怎么办。它管的是「技能从哪来、可不可信」，与[技能管理](#/docs/console-skills)的安装页配套。

**你在这里可以**：

- 给**未签名技能**定政策：**允许**（不做任何提示）/ **警告**（默认；照常安装，但要多确认一步并记一条警告）/ **拒绝**（直接装不上）。改动当场影响安装页的预检结果。
- 在**信任的签名密钥**里添加密钥（填标签和公钥），密钥标识由界面自动算出，不用手抄。两句话要读懂：技能包里自带的公钥不产生任何信任；信任库为空时选了**拒绝**，会拒掉所有技能。

![信任与签名页：未签名技能政策与信任密钥列表](/docs-assets/console-settings/zh/S-console-set-05-trust.png)

> **注意**：你在授权卡上勾过「以后不再询问」的页面操作不在这页。它们在**连接**组**页面技能**页的**已记住的页面操作**区块里，逐条**撤销**或**全部撤销**，撤销入口的样子与详细步骤见[连接](#/docs/console-connections)；授权卡本身的规则见[让助手操作页面](#/docs/page-actions)。

**常见用法**：从不明来源装过技能之后，把**未签名技能**改成**警告**或**拒绝**，再往技能库里添东西时心里就有底了。

### 隐私与用户画像（Privacy & User Modeling）

**做什么用**：回答「它记了我什么」，并让你看得见、改得动、带得走。更完整的数据去向说明见[隐私与数据去向](#/docs/privacy)。

总开关**从你的回答里学习**出厂默认**关**：关了就不记录，画像保持空白（Demo 为了演示默认打开，你在 Demo 里看到它是开的）。打开后，它会记录助手问过你什么、你答了什么，再提炼成一份画像，在后续对话里发给模型——你在表单里填的每一项都可能成为模型输入。

**看得见**。**模型知道的关于你的信息**不是一团黑盒：画像是一条条能读懂的大白话结论，每条带**高置信**或**低置信**标记，你可以逐条读。这些是从过往回答推断出来的，不是你明说过的。

![画像条目列表：每条是一句可读结论，带把握程度标记](/docs-assets/console-settings/zh/S-privacy-02-profile-entries.png)

**改得动**。每条都能单独删掉（有二次确认；弹窗上的取消按钮目前显示英文「Cancel」，不是点错了地方），不是只能整份清空——哪条不对删哪条。这件事和交互卡上的建议值、表单里的自动建议是同一件事的两端：那边它凭这些条目给建议，这边你把不认可的条目拿掉（见[助手向你要东西：六种交互卡](#/docs/interactions)、[说一句话，它替你把表填好](#/docs/case-fill-form)）。

![删除单条画像时的确认](/docs-assets/console-settings/zh/S-privacy-03-delete-confirm.png)

**带得走**。**导出**把画像存成一份文件，导出前可逐条取消勾选不想带走的；**导入**前会先给一份变化预览：新增几条、覆盖几条、这份画像来自哪个站点，看清楚再确认。

![导入前的变化预览：新增与覆盖条数、来源站点](/docs-assets/console-settings/zh/S-privacy-04-import-diff.png)

有一条硬规矩：画像文件里混进像密码、密钥的内容，**导出和导入都会被直接拒绝**，不是警告后放行。理由是这种文件常被顺手发邮件、丢进网盘，一旦裹带凭据就是长期泄漏。导入被拒时会弹出标题为**导入失败**的弹窗——里面的失败原因目前显示英文原文，那是底层抛出的原始消息，不是页面坏了。

![含凭据的画像被拒绝的提示](/docs-assets/console-settings/zh/S-privacy-05-credential-rejected.png)

另外几件可以做的事：

- 关掉总开关时会追问一次：**一并清除**还是**保留**已有的记录——只关开关不删数据。
- **清除行为记录**与**清除提炼出的画像**是两个独立按钮，都要点第二下才真删；删画像不删原始记录，反之亦然。
- **立即提炼**拿已存的记录重新汇总一次；画像为空时点它不会凭空造条目，只会给一句明确的空结果说明。
- **加密存储**默认开：本机的记录与画像是加密存放的。
- 两个上限：发给模型的画像默认不超过 4 KB（超出先丢较旧、把握较低的条目）；行为记录默认最多留 500 条（超出丢最早的）。

![隐私与用户画像页：总开关、画像列表与清除按钮](/docs-assets/console-settings/zh/S-console-set-06-privacy.png)

**常见用法**：发现某条画像说得不对——当场删掉那一条，不用整份清空。

### 外观（Appearance）

**做什么用**：助手面板与控制台自己的主题和语言——和你所在网站的外观无关。这是唯一改动入口：对话头部的「切换语言」入口改的也是这里，见[对话界面导览](#/docs/chat-tour)。

**你在这里可以**：

- **主题**：**浅色** / **深色**，只改助手面板与控制台自己的配色，不改你所在的网站（本文档页面始终是暗色，两边互不影响）。
- **语言**：English / 中文。界面文案是完全双语的，一切换，控制台与对话两侧的每一句文案一起变。
- **语音识别语言**：语音输入按哪种语言识别，默认**跟随界面语言**——界面切成英文，听写就跟着按英文识别。

所有切换都当场生效，不用刷新；刷新或隔天再打开，选择也保持。主题与语言是同一份设置：不管从对话面板还是控制台进这页，改的都是同一处。

![外观页：主题、语言与语音识别语言](/docs-assets/console-settings/zh/S-console-set-07-appearance.png)

**常见用法**：界面语言不对时来这页切——不用去动浏览器的语言设置。

### 关于与诊断（About & Diagnostics）

**做什么用**：报问题时该带什么信息，都在这页。

**你在这里可以**：

- 看**版本**号：报障时第一句会被问到的就是它。
- 看**存储用量**（已用 / 共多少）；系统没上报时显示短横线，不是坏了。
- 展开**已接线能力**：某项显示「未接线」，对应入口就会隐藏——「为什么我这里没有这个按钮」在这找答案。
- 点**导出**下载诊断文件：版本、技能清单、运行配置都在里面，模型密钥会被剔除。报问题时附上它；完整排错流程见[常见问题与排错](#/docs/faq)。

![诊断导出按钮](/docs-assets/console-settings/zh/S-console-set-11-diagnostics.png)

![关于与诊断页：版本、存储用量、已接线能力与危险操作区](/docs-assets/console-settings/zh/S-console-set-08-about.png)

页面最底部是**危险操作**区：**重置**把全部运行配置恢复为出厂默认，你配过的模型凭据会一并清空，有二次确认、无法撤销；技能、会话、审计日志、信任密钥都不动——它重置的是设置，不是数据。

**常见用法**：设置改乱了又懒得逐项还原——先在对应页点**恢复默认**，全乱了再用这里的**重置**。

## 网页版与扩展版的差别

八个设置页两种形态都有，内容基本一致，差别在两点：

- **存在哪**：两边的设置都只存在当前这台设备的这个浏览器里，不跟账号走——换浏览器、换设备要重新设置，画像也不会同步过去（这正是画像提供导出与导入的原因）。
- **个别开关的用武之地**：**允许读取下载的文件**对应的是扩展版「让它看你刚下载的那个文件」的能力（见[让它看你刚下载的那个文件（仅扩展版）](#/docs/downloaded-files)）。网页版多数系统没接这个能力，开关旁的说明会写明「开启还要求宿主已接上取件实现」，开了也没有实际效果。

## 出问题了怎么办

**改了设置，对话里没变化。** 改动对下一次运行生效，正在进行的那次不受影响——重新发一次再验证。设置是即时保存的，不用找「保存」按钮；切走再切回来、刷新页面，看到的都应是新值。

**忘了自己改过什么。** 每页底部的**恢复默认**只还原本页（有确认）；要全部还原，用**关于与诊断**页底部**危险操作**区的**重置**——注意它会同时清空你配过的模型凭据。

**技能联网或取数被拒。** 到**沙箱与安全**页：先确认**网络策略**不是「全部拒绝」，把要访问的地址加进**白名单**，用**试跑 URL** 当场确认放行，再回对话重跑。

**某个开关置灰，或整组设置不见了。** 置灰多半是当前模型不支持工具（**智能体能力**一组，页面上有说明）；整组不见是你所在的系统没提供对应能力——到**关于与诊断**页的**已接线能力**里核对。
