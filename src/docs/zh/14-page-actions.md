# 让助手操作页面

助手不只能读页面，还能替你动手：填表、点按钮、切页面。这章讲它会做什么、哪些先问你，以及不同意、反悔了怎么办。

## 你能做什么

- 一句话让助手替你填表、点按钮、切页面
- 分清哪些操作直接做、哪些一定先问你
- 勾「以后不再询问」，免去反复打断
- 在控制台里撤销已记住的授权

## 它能替你点什么、填什么

打开 [Demo](/demo) 说一句 `帮我打开缺陷管理页面`，它会把这个系统切到那一屏。切屏不算改动数据、不会打断你；动页面内容（点、填、选、提交）是另一套规则，见下一节。

## 你可以直接这样说

照左边这样说就行：

| 你这样说 | 它就这样做 | 会先问你吗 |
| --- | --- | --- |
| 「表格往下滚，把剩下的行看完」 | 向下滚动，滚到底自己停 | 一定先问 |
| 「把这一行的加号点开」 | 点那个图标，展开详情 | 一定先问 |
| 「每页改成 50 条」 | 在「每页多少条」下拉里选一项 | 不问，直接做 |
| 「备注里写上 ××」 | 往输入框里填字 | 不问，直接做 |
| 「点保存」「打开这条需求」 | 点按钮、链接或列表行 | 一定先问 |
| 「把这个开关打开」 | 置成开；已经是开的就不动 | 一定先问 |
| 「填好了，提交吧」 | 提交表单 | 一定先问 |
| 「把这张截图传上去」 | 允许后弹出系统文件选择框，你亲手选 | 一定先问 |
| 「回上一页」 | 返回上一页（浏览器历史） | 一定先问 |

![在表格上点加号展开行详情的授权卡](/docs-assets/page-actions/zh/S-actions-08-expand-consent.png)

表里的说法都能在 Demo 里原样试。

**它做不到的**：**拖拽**（拖卡片换列、拖文件上传、滑块验证）和**横向滚动**（宽表右侧的列）都做不了；页面之间只会返回上一页，不会替你输入新网址。

## 哪些事它会先问你

不是所有操作都要你点头，规则是分级的（以 Demo 的设定为例）：

| 它要做的事 | 会不会先问你 | 为什么 |
| --- | --- | --- |
| 往输入框里填字、在下拉里选一项 | 不问，直接做 | 还没提交，填错了你看得见、改得回来 |
| 点按钮、拨开关、提交表单、上传文件、滚动、返回上一页 | 一定先问 | 这些会真的写进系统 |

一句话记住：**它可以自己把整张表填满，但按下「提交」之前一定会停下来问你。**

![一张被自动填好的表单：多个字段已有内容，提交前弹出授权卡](/docs-assets/page-actions/zh/S-actions-07-filled-form-consent.png)

表单已填满，说明填写没打断你；授权卡挡在提交前，说明写进系统前一定问你。示例运行结果，你的实际输出会有所不同。

> **注意**：免确认的动作种类由你所在的系统决定。这里按 Demo 的设定讲，你用的系统可能划得更严。

## 动手之前先问你

需要你点头的操作会弹出**需要授权**卡片——真正改动页面之前，必须先得到你的同意。卡上写清三件事：

1. 它要做什么、动哪个东西，措辞形如「允许助手点击「{target}」吗？」；填字时连内容都原样摆在卡上（「允许助手在「{target}」中填入：」），批准前看得清内容。
2. 两个按钮：**允许**和**拒绝**。
3. 一个「以后不再询问」的选项（后面细讲）。

![完整的页面操作授权卡，含操作描述、允许与拒绝按钮](/docs-assets/page-actions/zh/S-actions-01-consent-card.png)

![授权前后的页面对比：允许之后表单真的被改动](/docs-assets/page-actions/zh/S-actions-03-page-changed.png)

点**允许**后页面变化立即可见。示例运行结果，你的实际输出会有所不同。

![授权流程：弹授权卡，允许、允许并记住、拒绝三个出口](/docs-assets/page-actions/M-15.svg)

允许它才动手；允许并记住以后不再问、可在控制台撤销；拒绝它就不做。

点**拒绝**不会毁掉整轮任务：只是这一个动作没做成（这次工具调用显示**失败**并附原因），页面不变，助手接着往下走。拒绝也会记进控制台的审计日志（见[治理与复核](#/docs/console-governance)）。

![拒绝授权后的对话：助手说明该操作未执行，任务继续](/docs-assets/page-actions/zh/S-actions-04-declined.png)

助手会明说这一步没做，再继续其余部分。示例运行结果，你的实际输出会有所不同。

## 它怎么知道自己点到哪了

它点完就自己接着干——它拿得到每次操作的去向：

| 发生了什么 | 它接下来怎么做 |
| --- | --- |
| 打开了新页面 | 切过去读那一页 |
| 当前页跳到了新地址 | 继续在这一页上读 |
| 弹出了对话框 | 在对话框里接着操作 |
| 页面没有变化 | 它知道这次没点成，会换个办法 |

另外两件它也会自己做：**按后退**（同样要先经你同意，除非勾过不再询问）和**滚动**（只在页面表明还有看不到的内容时才滚，滚到底就停）。

## 让它别每次都问

授权卡上有一个**以后不再询问此类操作**的选项。勾选后点**允许**，同类操作以后就直接做，不再打断你。Demo 里这个选项写明了记住的范围，形如「以后不再询问 本页面 里的「提交」操作」——记住的是「这个范围里的这一类操作」，不只是这一个按钮。

![授权卡上的「以后不再询问」选项](/docs-assets/page-actions/zh/S-actions-02-remember.png)

勾选并允许后，同类操作不再弹卡。

有一条硬性例外：**密码框永远不会被记住**。凡是密码类控件，每一次都要你亲自确认，卡上不会出现这个选项；要填的值在卡上显示为一串圆点，不明文展示。

## 反悔了怎么办

打开控制台（管理技能、调整设置的地方），进**页面技能**页的**已记住的页面操作**区块（界面原文：「选择了“以后不再询问”的操作。撤销后会恢复逐次确认。」），逐条点**撤销**或点**全部撤销**清空。撤销立刻生效，不用重新加载页面，下一次同类操作会重新弹卡。这一页的其他内容见[连接](#/docs/console-connections)。

![控制台「已记住的页面操作」区块，含撤销与全部撤销按钮](/docs-assets/page-actions/zh/S-actions-06-revoke.png)

已记住的授权逐条列出，可单条或一次清空。

要分清：撤销收回的是「不再询问」的记性。已经执行完的操作撤不回来——它真的写进系统了，需要你自己在页面上改回来。

## 有些事它不会做

**能读不等于能操作。** 你所在的系统给助手划了可操作范围，范围外一律拒绝，连授权卡都不弹——能读出列表数据，旁边的删除按钮却可能不在范围里。被拦下的调用在**运行流程**里显示**被策略拒绝**并附**拒绝原因**（四种状态见[看懂助手在做什么](#/docs/transparency)）。

![显示「被策略拒绝」状态的页面操作](/docs-assets/page-actions/zh/S-actions-05-policy-blocked.png)

你自己手动打开的对话框它也不动——只有它自己操作打开的才能接着操作，授权卡上会多出一句「该对话框不在常规允许清单内，是本次任务打开的」。系统没开放页面操作时，它会直接说做不到。

## 登录状态下的操作

助手在你已登录的页面上操作，系统看到的就是你本人。授权卡弹出来看清再点**允许**；有疑虑就点**拒绝**。

## 网页版与扩展版的差别

| | 网页版 | 扩展版 |
| --- | --- | --- |
| 能操作的页面 | 只有助手所在的这一个页面 | 你打开并交给它工作的任意网页 |
| 确认、记住、撤销 | 同一套规则 | 同一套规则 |

扩展版能操作的页面更多，约束不变：同样要授权、密码框同样永不记住，只能动工作集内的标签页，你自己开的它看不到（见[跨标签页工作](#/docs/tabs)）。

## 出问题了怎么办

- **它说找不到要操作的东西。** 页面一变它记下的元素就失效了，让它重新读一次再试。
- **授权卡弹得太频繁。** 在卡上勾**以后不再询问此类操作**；或把任务说小一点。
- **卡片放太久没理，运行自己结束了。** 等回答有时限，超时以「表单未及时提交，运行已停止」结束，重发即可。
- **误点了允许。** 已提交的操作没法自动撤回，在页面上手动改回来；勾过「不再询问」的，到控制台把那条授权撤掉。
