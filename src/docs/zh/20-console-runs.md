# 运行记录

你在对话里发起的每一次运行，控制台里都留着一条对应的记录：成功还是失败、跑了多久、用了哪些技能、产出了什么文件。哪次回答不对劲、想知道助手记住了你什么、没跑完的任务想接着跑——都到控制台「运行」分组来找。控制台怎么打开，见[控制台导览](#/docs/console-tour)。

## 你能做什么

- 按状态筛出失败的运行，一眼看到成功率与耗时
- 用运行 ID 精确定位任何一次运行，回放它的每一步
- 下载某次运行产出的文件
- 查看助手在各层记忆里存了什么，不认可的逐条删除
- 恢复被打断的运行，从上次停下的地方接着来

## 对话与控制台：同一件事的两个视图

你在对话里每发一条消息，助手为回答它做的那一整套动作就是**一次运行**：对话里它呈现为「运行流程」卡片（见[看懂助手在做什么](#/docs/transparency)），控制台里它沉淀为一条**运行记录**。两边说的是同一件事——对话给你看当下这一次，控制台留着全部历史。

连接两边的钥匙是**运行 ID**。最省事的一条路不用复制：悬停助手的那条回答，点**查看追溯**，直接落到运行详情页的这一次运行。消息不好找时，展开「运行流程」卡片点**复制运行 ID**，到运行记录页或运行详情页的搜索框里粘贴过滤，也能找到它。

![M-21 从一次对话到一条运行记录](/docs-assets/console-runs/M-21.svg)

一次提问产生一条运行记录；记录可展开为详情：时间线、工具调用、模型往返、产物。

下面按侧栏「运行」分组里的顺序逐页说明。

### 运行记录（Activity）

**做什么用**：每次运行都在这里留一行——状态、开始时间、结束原因、用到了哪些技能。想回答「最近它干得怎么样」「哪次失败了」，来这页。

页面顶部是四张指标卡：**成功率**、**平均轮次**、**平均耗时**、**总运行数**。它们统计的是全部运行，不随下面的筛选变化。指标卡下方若出现**近期失败**（最多 5 条），每个运行 ID 都可以点，点了直接跳到那次运行的详情。

**你在这里可以**：

- 在搜索框里按运行 ID 或技能名过滤（占位文字是「搜索运行 ID 或技能…」）
- 用**全部状态**下拉只看某一类：`completed`（已完成）、`failed`（失败）、`cancelled`（被中止）、`running`（进行中）；搜索和筛选可以叠加
- 用表格下方的翻页和每页条数翻查更早的记录
- 点某一行的运行 ID，跳到运行详情页看完整记录

![运行记录页：指标卡、近期失败与可筛选的运行列表](/docs-assets/console-runs/zh/S-console-runs-01-activity.png)

找失败运行不用翻页：状态下拉选 failed 就只剩它们；近期失败里的运行 ID 点了直达详情。

**常见用法**：助手刚才那次回答不对劲，到本页把状态筛成 `failed`，看「结束原因」列。这一列显示的是英文代号，与[看懂助手在做什么](#/docs/transparency)一章「它为什么停了」里的提示一一对应——比如 `max-turns` 就是对话里的「达到轮次上限，运行已停止」。要深挖就点运行 ID 进详情。

### 运行详情（Inspector）

**做什么用**：把一次运行完整回放给你看，是排错的终点。

页面左边是运行列表（可搜索、可翻页），点一条，右边展开它的档案：

- **LLM 轮次**：助手和模型来回问答了几次，每轮一张卡：第几轮、几条消息、几个工具；标着「最终答复」的那轮，就是它给出结论的时刻。
- **任务清单**：拆过任务的话，这里给出清单最终状态——哪项完成、哪项委派给了别的技能，与对话里的任务清单一致；没拆任务不显示这一区。
- **追溯时间线**：按时间排的每一步，按类别着色，技能、模型、工具、界面、产物一眼可分。点开任意一步看详细数据；工具调用带耗时，被安全边界拦下的那步标着「被策略拒绝」。
- **产物**：这次运行产出的文件：文本类就地**预览**，图片直接显示，其余点**下载**。

进行中的运行，所在系统支持时这里有**取消运行**；不支持会明说，不会是点了没反应的按钮。

**你在这里可以**：

- 从对话里点**查看追溯**直达某次运行；在运行记录页点运行 ID 也会跳到本页并选中它
- 这样直达的运行即使不在当前页，也会被提到列表最前并标注「按 id 定位」——这不是分页坏了
- 把运行 ID 粘进本页搜索框只是过滤列表，不会出现「按 id 定位」标注
- 逐轮读 LLM 轮次卡，弄清它在哪一步做了错误判断

![运行详情页：左侧运行列表，右侧一次运行的完整档案](/docs-assets/console-runs/zh/S-console-runs-02-inspector.png)

选中一条运行，右边就是它的轮次、清单、时间线与产物。

![从对话点「查看追溯」直达，目标运行被标注「按 id 定位」](/docs-assets/console-runs/zh/S-console-runs-04-locate-by-id.png)

「查看追溯」直达时，目标运行不在当前页也会被提到最前，标注「按 id 定位」；粘 ID 搜索只是过滤。

![一次失败运行的详情，时间线上标出失败原因](/docs-assets/console-runs/zh/S-console-runs-05-failed-run.png)

失败的那一步在时间线上有据可查；结束原因的代号与对话里的终止提示说的是同一件事。

**常见用法**：悬停助手那条回答点**查看追溯**直达本页，逐步回看：哪一轮理解偏了、哪次工具调用失败、原因是什么。消息不好找就复制运行 ID（步骤见[看懂助手在做什么](#/docs/transparency)）到搜索框过滤。记录已不在时，页面会明说找不到并原样显示这个 ID，不会悄悄换成别的运行给你看。

### 会话与记忆（Sessions & Memory）

**做什么用**：助手记住了什么、在哪层记的，没跑完的运行停在哪。

**对话会话**：全部会话（含已归档）的列表，点一个只读翻看消息。重命名、归档等管理在对话面板做，见[管理会话](#/docs/sessions)。

**记忆浏览器**：回答「它记了我什么」。记忆分三层，名字即页面上所示：

| 层 | 记的是什么 | 保留范围 |
| --- | --- | --- |
| `session` | 某段会话里的临时记录 | 跟着那段会话走 |
| `skill` | 某个技能自己记的笔记 | 跨会话保留 |
| `user` | 助手对「你」的了解 | 跨会话、跨技能保留 |

选一层、填标识符、点**加载**就能看到每一条；不该留的点**删除**。画像在设置的「隐私与用户画像」页有更好读的视图（见[设置](#/docs/console-settings)），数据去向见[隐私与数据去向](#/docs/privacy)。

**中断的运行**：运行停在等你回答的卡片上时刷新页面，会留一条快照。点**恢复**回到对话，那张卡片会重新出现。但停在**授权卡**上的运行中断后不能恢复，见[提问、回答与打断](#/docs/chat-basics)。旧版本写下的快照会列出但不能恢复。

![会话与记忆页全景](/docs-assets/console-runs/zh/S-console-runs-03-sessions.png)

三块同页：会话、记忆、中断的运行。

![记忆浏览器的条目列表](/docs-assets/console-runs/zh/S-console-runs-06-memory.png)

记忆逐条可见，逐条可删。

**常见用法**：怀疑它记了不该记的——选 `user` 层加载逐条看，不认可的直接删。

> **注意**：本页删除或清空会话，确认后不可撤销，见[管理会话](#/docs/sessions)。

## 网页版与扩展版的差别

三个页面本身两者一致，差别在记录的内容：扩展版的运行可以跨标签页，时间线和工具调用里可能出现对其他标签页的读取与操作；网页版的记录只涉及当前站点。记录与记忆都存在本机浏览器里，换一台电脑、换一个浏览器都看不到。

## 出问题了怎么办

- **按运行 ID 搜不到那次运行。** 先核对 ID 有没有复制完整；再想想对应的会话是不是被删了——在对话面板里删除会话时，它的运行记录会一并删除（见[管理会话](#/docs/sessions)），找不回来。
- **点「查看追溯」后，详情页提示找不到这个 ID。** 这不是出错，是明确告诉你没有这条记录：多半是该运行已随会话删除。页面会把要找的 ID 原样显示出来，方便核对。
- **点「恢复」没反应或报错。** 两种情况：快照是很早的版本写下的（页面上有标注），本来就恢复不了；或者恢复需要对话面板在场——在 Demo 里先打开一次对话面板，再回来点恢复。
- **删了记忆条目，担心没删成。** 删除后列表会重新从存储拉取，条目消失即已删成；不放心就刷新页面再看一次。
