# 隐私与数据去向

用助手干活，绕不开一个问题：你说的话、它读到的页面、你传的文件，最后都去了哪？这一章按三类说清——留在本机的、会发给模型的、永不外发的——每一类都能在界面上核对，也都给你留了开关。

## 你能做什么

- 看清每类数据的去处：哪些留在本机，哪些发给你配置的模型服务，哪些永不外发
- 明白它的权限边界：你在界面上能看到、能操作的，它才能看到、操作
- 知道你传的 Word、Excel、pdf、图片各自实际发出去的是什么
- 关掉页面图片的外发、关掉「从你的回答里学习」、逐条删掉它记住的内容——开关位置见末尾那张表

## 一张图看清数据去哪了

助手跑在你的浏览器里：存数据的地方只有这个浏览器，发数据的方向是你在控制台 **大模型** 页自己配置的模型服务（怎么配置见[连接](#/docs/console-connections)）。

![M-33 数据去向图：会话、记忆、技能文件、设置留在本机；你的提问、页面内容、工具结果、附件内容发给模型；密码框的值永不外发](/docs-assets/privacy/M-33.svg)

三类去向一张图：左区存在本机，中区随对话发给你配置的模型服务，右区永不外发；Word 和 Excel 的原文件留在这台机器上，只把读出的文字发出去。

模型选哪档也决定去留：**Chrome 内置** 档的模型请求不出本机（代价是不支持工具、只剩纯聊天）；没配模型时的 **演示模型** 也不发起网络请求。见[选择模型](#/docs/models)。

## 它的权限就是你的权限

在谈「发出去的是什么」之前，先搞清一个更根本的问题：它能读到、能碰到的数据，边界在哪？答案是——它没有自己的通道，入口就是你眼前的这套界面。

- **读这条线**：它读的是浏览器画出来的页面内容，不是绕到后端接口取数。你在界面上能看到什么，它才能看到什么；屏幕上不显示的东西——收起的面板、没切到的页签、隐藏的字段——不进它的视野。你所在系统提供的页面工具，取的数与页面给你看的同出一源（Demo 里两者读的就是同一份数据）。
- **写这条线**：它能点的按钮、能填的框，都是页面上本来摆给你的控件，执行的是和人手一样的点击与填写；在你已登录的页面上操作，系统看到的就是你本人在操作（规则见[让助手操作页面](#/docs/page-actions)）。

**所以**：它不会读到你在后端没权限看的数据，也动不了你无权维护的数据——助手是在你的权限范围里替你读、替你动手，不越俎代庖。在这个底子上，范围还可以更小：你所在的系统能划定排除区域，扩展版只在你交给它工作的标签页里读写（见[让助手读当前页面](#/docs/page-perception)、[跨标签页工作](#/docs/tabs)）。

> **提示**：「不越你的权」不等于「读了就不外传」——已经读到的内容哪些会发给模型，是下一节的事。

## 什么会被发给模型

每一轮对话，以下内容会一起发给你配置的模型服务：

- **你的提问**，以及当前会话里之前的对话内容（回放条数有上限，可在[设置](#/docs/console-settings)里调）。
- **助手读到的页面内容**。读哪块由你所在的系统划定，读了哪块、排除了哪块都写在对话里（见[让助手读当前页面](#/docs/page-perception)）。
- **每次工具调用的结果**。工具是助手能执行的一个具体动作，由谁提供，调用就到谁那里：你所在系统提供的在系统侧执行；你在 **MCP 端点** 页接的远程服务，会收到那一次调用的内容。
- **你挂进消息的附件**——按类型发的不一样，下一节逐个说。
- **画像里提炼出的那几条结论**——只有开着「从你的回答里学习」才有这一项，见下文「助手记住了什么」。

这些内容离开这台机器之后，适用的是你选用的模型服务方的数据政策，以你所在系统的实际配置为准。

## 什么永远不会被发送

**密码框里的值。** 它不进入页面感知的结果——就算系统忘了把它划进排除区域，它的值也不会进入助手的视野；页面上刻意隐藏的字段同理。它也不会被记住：凡是密码类控件，每一次都要你亲自确认，授权卡上不会出现「不再询问」选项，要填的值在卡上显示为一串圆点（操作规则见[让助手操作页面](#/docs/page-actions)）。

边界要说清：这不等于「所有敏感内容都不会被发送」——普通输入框里的内容，只要在被读取的区域内，就会随读取一起发给模型。涉及口令、证件、钱款的内容，别指望它替你分辨：让你所在的系统把那块区域划进排除范围，或别让助手读那一页。

## 我上传的那份文件呢

把文件挂进输入框不等于发出去——你点 **发送** 才算数。发出去的是什么，按附件类型分开：

| 你传的 | 实际发出去的 |
| --- | --- |
| 图片 | 图片本身；太大的先压缩，压缩的只是发出去的那份副本，你机器上的原文件不动 |
| 文本（txt、md、csv 等） | 文件里的文字，超过 32K 字符的部分会被截断 |
| 文件（pdf） | 整份文件，需要当前模型支持文档输入 |
| 文档正文（docx、xlsx） | 在你自己的浏览器里读成文字再发，发出去的只是读出来的正文文字——文档里的图片和排版不在其中——原文件不会整份发出去 |

> **仅扩展版**：让它读你下载目录里的文件，走的是同一条路、同一套格式，发出去的内容与手动上传完全一样；差别只在列清单、读文件都要你先点头（见[让它看你刚下载的那个文件](#/docs/downloaded-files)）。

## 页面里的图片

默认情况下助手只读文字，**一张图都不会往外发**。想让它连图一起看，先开开关：控制台 **设置** 组 **智能体运行时** 页 **多模态** 一节里的 **页面图像抓取**（**连接** 组 **页面技能** 页也有同一个开关）；出厂默认关，Demo 为演示默认开。关回去，文字照读、图片一张也不发。

![M-14 助手能看到页面的哪些部分](/docs-assets/page-perception/M-14.svg)

会读的是正文、表格、表单标签；密码框的值不读；页面里的图片由你的开关控制。

两个前提：模型能力标记为「可传图片」，且单条消息的图片有张数与大小上限。开启后的计数提示见[让助手读当前页面](#/docs/page-perception)。

![页面技能页：页面图像抓取开关与最近感知记录都在这一页](/docs-assets/console-connections/zh/S-console-conn-04-page-skills.png)

开关旁边就是 **最近感知记录**，每一次读取的时间与区域都可核对。

## 助手记住了什么

**先说记忆。** 助手记下的内容分三层（某段会话的、某个技能的、关于你的），都存在本机，控制台 **会话与记忆** 页的 **记忆浏览器** 里逐条可见可删（见[运行记录](#/docs/console-runs)）；它读到的记忆，和工具结果一样会进入当轮对话。

**再说画像——这一项最容易误会。** 控制台 **设置** 组 **隐私与用户画像** 页的总开关 **从你的回答里学习** 出厂默认关：关了就不记录，画像保持空白（Demo 为演示默认开）。打开之后，三样东西的去向要分开看：

| 东西 | 去哪了 |
| --- | --- |
| 你答过、选过的原始记录 | 留在本机，加密存放；最多留 500 条，超出丢最早的 |
| 从中提炼出的那几条结论 | 每一轮对话都随提示一起发给模型——不发过去，它就无从知道你的习惯。有长度上限（默认 4096 字节，超出先丢较旧、把握较低的条目） |
| 这份画像本身 | 只存在这台机器上，不跨设备同步；换设备就用导出、导入自己搬 |

所以「你的偏好只存在本地、不会外发」不成立：**原始记录不外发，提炼出的结论会作为背景交给模型。** 嫌哪条不该发，到 **隐私与用户画像** 页逐条删掉（有二次确认）；不想要这整件事，就关总开关，它会追问「一并清除」还是「保留」。完整说明见[设置](#/docs/console-settings)。

![隐私与用户画像页：总开关、画像列表与清除按钮](/docs-assets/console-settings/zh/S-console-set-06-privacy.png)

画像不是黑盒：每条是一句能读懂的大白话，逐条可删。

![画像条目列表：每条带把握程度标记](/docs-assets/console-settings/zh/S-privacy-02-profile-entries.png)

## 你能控制什么

| 我想控制 | 开关在哪 |
| --- | --- |
| 页面图片要不要随读取外发 | 设置 → 智能体运行时 → 多模态 → **页面图像抓取**（见[让助手读当前页面](#/docs/page-perception)） |
| 能不能发图片附件 | 同一节的 **图片附件**（见[附件、图片、语音与拍照](#/docs/attachments)） |
| 它要不要从我的回答里学习 | 设置 → 隐私与用户画像 → **从你的回答里学习**（见[设置](#/docs/console-settings)） |
| 它记住的某一条画像不对 | 同一页里逐条删除 |
| 它在各层记忆里存了什么 | 运行记录 → 会话与记忆 → **记忆浏览器**（见[运行记录](#/docs/console-runs)） |
| 技能脚本能不能联网 | 设置 → 沙箱与安全 → **网络策略**（见[设置](#/docs/console-settings)） |
| 已记住的授权（页面操作、下载文件） | 连接 → 页面技能 → **已记住的页面操作**，逐条 **撤销**（见[连接](#/docs/console-connections)） |
| 要不要它把对话存成技能 | 设置 → 智能体运行时 → **技能自动生成**（见[设置](#/docs/console-settings)） |
| 它能不能读下载的文件（仅扩展版） | 设置 → 沙箱与安全 → **允许读取下载的文件**（见[让它看你刚下载的那个文件](#/docs/downloaded-files)） |
| 用哪个模型——含在本机运行的一档 | 连接 → 大模型（见[选择模型](#/docs/models)） |

## 数据存在哪儿

会话与运行记录、三层记忆、画像与行为记录、装好的技能、你的设置——全部存在当前这台设备的这个浏览器里，不跟账号走：换浏览器、换设备都要重来，画像也不会自己跟过去（这正是它有导出与导入的原因）。

- 画像与行为记录加密存放，**加密存储** 默认开。
- 技能被用到时，说明书内容会作为对话背景交给模型；脚本在本机的沙箱（技能脚本的隔离运行环境，碰不到你的页面和数据）里运行，默认不能联网（放开方式见[设置](#/docs/console-settings)）。
- 模型密钥保存在本机，界面不明文显示；导出诊断文件时会被剔除（见[设置](#/docs/console-settings)）。
- 删会话没有撤销：会话与运行记录一并永久删除（见[管理会话](#/docs/sessions)）；浏览器的「清除站点数据」会把会话一起清空。
- 本机占了多少空间，在控制台 **关于与诊断** 页看 **存储用量**。

![关于与诊断页：版本、存储用量、已接线能力](/docs-assets/console-settings/zh/S-console-set-08-about.png)

## 网页版与扩展版的差别

存储规则两种形态一致：都存在本机；密码框的规则、图像开关、画像的行为也都一致。差别在**能读到多少**：

- 网页版只能读它所在的这一个站点；扩展版能读你打开的任意网页——会发出去的页面内容，来源因此更广。
- 能力变大，约束不变：密码框照样不读、照样永远不记住，图像抓取开关照样生效，读不到的内容它照样明说。

> **仅扩展版**：扩展版还能经你授权读下载目录——列清单一次卡、读文件一次卡；它拿不到文件在你磁盘上的位置，对文件只读。记住过的授权在 **页面技能** 页撤销，见[让它看你刚下载的那个文件](#/docs/downloaded-files)。

## 出问题了怎么办

- **担心画像里某条被发给模型。** 到 设置 → 隐私与用户画像 逐条读、逐条删；整件事都不想要，就关掉 **从你的回答里学习**，关闭时选「一并清除」。
- **对话里出现了抓图计数，而你不想发图。** 关掉 **页面图像抓取**（设置 → 智能体运行时 → 多模态）；附件图片另有开关 **图片附件**，在同一节。
- **想核对它某次到底读了哪块。** 看那条回答上的感知提示——读了哪块、排除了哪块都写着；事后到 **页面技能** 页的 **最近感知记录** 逐条核对。
- **想把本机的数据清干净。** 画像与原始记录是两个独立的清除按钮，都要点第二下才真删；会话确认后不可撤销；全部清空用浏览器的「清除站点数据」。
