# 控制台导览

控制台是管理技能、查看运行记录、调整设置的地方。这一章解决三件事：怎么打开它、它的 25 个页面怎么分布、怎么快速找到你要的那一页。本章所有画面都可以在 [Demo](/demo) 里打开控制台实际对照。

## 你能做什么

- 打开控制台，认出六个分组各自管什么
- 用概览页判断助手最近跑得怎么样、有没有事要你处理
- 用命令面板按名字直达任意页面，不必记住位置
- 看页面顶部的页名和用途说明，确认自己来对了地方

## 什么时候需要控制台

日常对话用不上控制台——提问、让助手干活，都在对话框里完成。遇到下面这些事才进来：

- 装了新技能、想改技能，或把自己的技能打包给别人 → [技能管理](#/docs/console-skills)
- 某次回答失败或不对劲，想查清这次运行发生了什么 → [运行记录](#/docs/console-runs)
- 有候选技能等你审批，或想追溯谁在什么时候改了什么 → [治理与复核](#/docs/console-governance)
- 换模型、接外部工具、看当前页面提供了哪些工具和临时技能 → [连接](#/docs/console-connections)；撤销已经记住的授权也在这一组的 **页面技能** 页
- 调整助手的行为上限、权限、外观与隐私 → [设置](#/docs/console-settings)

这五类事对应第四部分的五章，本章只管把你带到门口。

## 怎么打开

**网页版**：控制台是你所在网站内部的一个管理页，入口由网站安排，一般在对话附近找「打开 Console」或「设置」这样的入口。在 Demo 里，点对话头部的 **设置** 即可进入：

1. 点页面右缘的 **展开 AI 助手**，打开对话抽屉（已打开就跳过）。
2. 点对话头部的 **设置**（齿轮图标，悬停会显示名字）。控制台在网站主区打开，落在概览页。

![Demo 对话头部的设置按钮，点它进入控制台](/docs-assets/console-tour/zh/S-console-tour-02-entry.png)

入口不藏在菜单里：对话头部最右侧的齿轮就是它。

对话里还有两个直达入口：消息操作栏的 **查看追溯** 会带你到这次运行的详情页；候选技能卡上的 **去审批** 会带你到审批队列。它们各自的用处见 [看懂助手在做什么](#/docs/transparency) 与 [治理与复核](#/docs/console-governance)。

> **仅扩展版**：控制台是扩展的选项页，在浏览器标签页里打开。点对话里的 **设置**、**去审批** 都会打开选项页并直接落到对应分区；不开对话也能进——在浏览器的扩展管理里找到这个扩展，打开它的「选项」页。

## 六个分组分别管什么

左侧栏就是控制台的全部目录：六个一级分组，点开分组是它里面的页面，共 25 页。这里讲的顺序与你在界面上看到的完全一致。

![控制台全景：左侧栏从上到下是六个分组，右侧是页面内容](/docs-assets/console-tour/zh/S-console-tour-01-shell.png)

左侧栏的六个分组与下表一一对应。

| 分组 | 管什么 | 页数 | 详见 |
| --- | --- | --- | --- |
| 概览（Overview） | 工作区健康度：运行指标、待处理事项、最近的运行 | 1 | 本章 |
| 技能（Skills） | 装了什么技能、改技能、安装与导出、检查技能文件有没有被改动 | 4 | [技能管理](#/docs/console-skills) |
| 运行（Runs） | 每次运行的记录与详情、会话与助手记住的内容 | 3 | [运行记录](#/docs/console-runs) |
| 治理（Governance） | 新技能进库前的审批、一份改不掉的改动流水账、版本回退、稳定性验证、使用统计 | 5 | [治理与复核](#/docs/console-governance) |
| 连接（Connections） | 用哪个模型、外部工具服务、当前页面提供的工具与临时技能 | 4 | [连接](#/docs/console-connections) |
| 设置（Settings） | 助手最多干多久、技能脚本有多大权限、生成的界面长什么样、快捷指令、信任、隐私、外观、关于 | 8 | [设置](#/docs/console-settings) |

![M-19 控制台地图：六个分组与全部 25 个页面](/docs-assets/console-tour/M-19.svg)

找不到某页时先看这张图：每个节点对应侧栏里的一个页面，节点上的名字与界面一致。

两个认路的技巧：

- 你当前在哪一页，看页面顶部就知道——每页开头都写着页名和一句「这一页是干什么的」。
- 侧栏可以整个收起来：点侧栏顶部的收起按钮（悬停显示「收起设置」），整栏隐藏、主区变宽，页面左缘会留下一个展开按钮（悬停显示「展开设置」），点它恢复。窄屏下侧栏会变成浮层，选中页面后自己收回去。

## 概览页（Overview）：一眼看健康度

**做什么用**：进控制台先到这里。它回答两个问题——助手最近跑得怎么样，有没有事要你处理。

**你在这里可以**：

- 看四张指标卡：**运行次数**、**成功率**、**平均耗时**、**待审核**（等你审批的候选技能数）。
- 在 **近期运行** 里看最近五次运行：每次的运行 ID、状态、用了哪些技能、开始时间。点 **查看运行** 进运行记录页看全部。
- 处理 **待处理** 里的事：有候选技能等你审批、或最近有运行失败时才出现条目，点条目直接跳到对应页面；一切正常时显示「暂无待处理事项」。
- 在 **大模型用量统计** 里按时间维度（今天、近7天、本月等）看 API 请求次数、Tokens 用量与消费金额的图表，图表可以在次数与 Tokens 之间切换。

![概览页：四张指标卡、近期运行列表、待处理与用量统计](/docs-assets/console-tour/zh/S-console-tour-03-overview.png)

指标是真实运行的汇总；还没跑过任何对话时，近期运行会显示「暂无运行记录」。

**常见用法**：感觉助手最近常失败，先来这页看一眼——成功率掉了多少、待处理里有没有失败运行，点失败那条直接进运行记录页接着查，后续步骤见 [运行记录](#/docs/console-runs)。

页面上还有一个 **接线自检** 区：控制台依赖的三块数据来源（**运行追踪**、**治理门面**、**连接门面**）各显示 **已接线** 或 **未接线**。Demo 里三项都已接线；看到未接线，说明你所在的系统没接那块数据，对应的功能会空着，找系统的提供方。

## 快速跳转

页面多了记不住位置，用命令面板：

1. 在控制台里按 `⌘K`（Mac）或 `Ctrl+K`（Windows），打开 **命令面板**。
2. 输入页面名或用途里的词，中文、英文都认——搜「审计」或「audit」都能命中。
3. 用方向键选中，回车直达。列表里每条都写成「分组 / 页面」并带一句用途说明；找不到匹配会显示「无匹配结果」。

![命令面板：输入即筛选，每条结果显示分组、页名与用途](/docs-assets/console-tour/zh/S-console-tour-04-palette.png)

命令面板只做一件事：把你送到那个页面，页面里的操作仍由你自己完成。

## 网页版与扩展版的差别

控制台本身——六个分组、25 个页面、命令面板——两种形态是一样的，差别在它开在哪：

| | 网页版 | 扩展版 |
| --- | --- | --- |
| 开在哪 | 你所在网站内部的一个管理页 | 扩展的选项页，在浏览器标签页里打开 |
| 从对话直达 | 对话头部的 **设置**、消息上的 **查看追溯**、候选技能卡的 **去审批**，都会落到控制台对应页面 | 点 **设置**、**去审批** 会打开选项页并落到对应分区（如大模型页、审批队列） |

![扩展版的控制台：作为扩展选项页开在浏览器标签页里](/docs-assets/console-tour/zh/S-console-tour-05-extension.png)

形态不同，内容相通：在一种形态里认识的页面，换到另一种形态还在原来的分组里。

## 出问题了怎么办

**找不到控制台的入口。** 网页版的入口由你所在的系统安排：Demo 里点对话头部的 **设置**；别的系统留意「打开 Console」这类入口，找不到就问系统的提供方。扩展版从浏览器的扩展管理里打开它的「选项」页。

**命令面板搜不到想去的页。** 它按页面名和用途做包含匹配，中文、英文都能搜，换个说法试试——比如「审计」或「audit」。还要注意它只管跳转，不能替你完成页面里的操作。

**左边一栏不见了。** 多半是被收起了：点页面左缘的展开按钮（悬停显示「展开设置」）即可恢复。窄屏下侧栏本来就会收成浮层，选中页面后自己收回去。

**概览页没有数据。** 先看 **接线自检**：有 **未接线** 项，说明这个部署没接那块数据，找你所在系统的提供方；全部 **已接线** 但 **近期运行** 是空的，就是还没跑过对话，去聊一句再回来看。
