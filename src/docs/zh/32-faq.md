# 常见问题与排错

带着一个症状进来，找到原因和下一步。每条症状都给出可执行的处理，而不是一句「请联系管理员」了事。

![M-32 排错决策树：从「出什么问题了」分叉到错误卡、没有响应、中途停止、结果不对、附件语音、页面、技能、断网几大类症状，叶子指向本章对应小节](/docs-assets/faq/zh/M-32.svg)

## 怎么用这一章

按**你看到的现象**找，不需要先判断问题出在哪个模块。界面上的提示原文用引号标出，方便你逐字对照。上面这张图的文字版速查：

| 你看到的 | 去这一节 |
| --- | --- |
| 一张「出错了」的卡片 | 错误卡上写了什么 |
| 发出去没反应，或它只会聊天 | 助手没有响应 |
| 运行提前结束 | 运行中途停了 |
| 答案和页面、文档对不上 | 结果不对或跑偏 |
| 图片、语音、拍照、文件传不出 | 传不了图 / 用不了语音 |
| 页面读不到、点了没反应 | 页面读不到 / 操作没生效 |
| 技能调不到或报错 | 技能相关的问题 |
| 断网、弱网、关了标签页 | 断网、弱网与多标签页 |
| 它的行为和预期不一样 | 这些不是故障 |
| 上面都没有 | 这里查不到怎么办 |

> **仅扩展版**：「这些不是故障」里涉及工作集与多页处理的两条，只有扩展版会遇到——网页版没有跨标签页能力。

## 错误卡上写了什么

运行出错时，对话里出现一张标题为「出错了」的卡片：一句针对这次错误的建议，加两个按钮——**打开设置**（直达相关设置页）和 **关闭**。

![一个典型的错误卡：标题「出错了」、一句建议文案与「打开设置」「关闭」两个按钮](/docs-assets/faq/zh/S-faq-01-error-card.png)

拿不准先做通用的：「关闭后重试。展开上方的运行步骤可以看到它停在哪一步。」重发一次还出错，就按卡片上那句话到本章对应小节找——那句话在下面各节里都用引号原样列出。

## 助手没有响应

**发出去完全没反应，或提示「尚未配置大模型」。** 还没有可用的模型。点 **配置大模型** 去添加一个：地址和密钥的填法见[连接](#/docs/console-connections)，怎么选见[选择模型](#/docs/models)。

**错误卡写「请检查设置中的模型配置，或重试。」** 模型不可用，或这次请求失败了。先查网络再重试；自己配过模型，到控制台 **大模型** 页检查配置，见[选择模型](#/docs/models)。刚断过网也会见到这张卡，恢复后直接重发即可，见本章「断网、弱网与多标签页」。

**它停着不动，像在等什么。** 多半是弹了卡片等你回答：往上翻找到没答的那张，答完运行继续。卡片找不到了，点输入区上方「正在等你操作：…」旁边的 **去表单** 跳回去，见[助手向你要东西：六种交互卡](#/docs/interactions)。

**它突然只会聊天，不调技能、不读页面。** 当前模型不支持工具：看模型能力标记是不是 **无工具**，换一个有 **可用工具** 标记的模型；自己配的模型，再检查大模型页的「支持工具调用」开关是不是被关了。见[选择模型](#/docs/models)。

## 运行中途停了

每次提前结束，界面都会给出一句原因。八种终止原因的完整对照在[看懂助手在做什么](#/docs/transparency)的「它为什么停了」一节，这里只收错误卡会直接告诉你的几条。

**「本次运行超出了总时长预算，请改用更小的任务。」或「运行已停止：达到总时长上限（N 秒）。可在『设置 › 智能体』中调整。」** 任务太大：拆成几步分几次说；确实需要更长的时间，错误卡上的 **打开设置** 直达上限调整页。见[看懂助手在做什么](#/docs/transparency)。

**「本次运行达到了轮数上限。」或「运行已停止：达到往返轮数上限（N 轮）。可在『设置 › 智能体』中调整。」** 它思考加执行的来回次数触顶了。处理同上：先拆任务，再考虑调上限。

**「等待你填写超时。」** 卡片等你回答有时限，超时运行就以「表单未及时提交，运行已停止」结束。重发一次，这次及时答，见[助手向你要东西：六种交互卡](#/docs/interactions)。

**「你已停止本次运行。」** 你自己点了 **停止**。无需处理，想继续就重新发一次。

**「生命周期钩子失败，运行已停止」** 不是你做错了什么，是系统内部的检查环节出了错。联系提供这个系统的人。见[看懂助手在做什么](#/docs/transparency)。

**「多次调用不存在的工具，运行已停止」** 它反复试图用一个不存在的工具，多半是当前技能和这个页面对不上。换个说法重试；仍不行就确认要用的技能已启用。见[看懂助手在做什么](#/docs/transparency)。

**「运行未正常结束」** 兜底提示，原因不明。先重试；反复出现就复制运行 ID，到[运行记录](#/docs/console-runs)里查。见[看懂助手在做什么](#/docs/transparency)。

## 结果不对或跑偏

**报告里的数字和页面上看到的对不上。** 数据是你提问那一刻取的，之后页面的变动它不知道。重新发一次，让它按最新数据重取。

**它的总结和你看到的内容对不上。** 它只读了感知区域里圈定的那块，也只读当前显示着的内容。先翻到想让它看的部分，再问一次，见[让助手读当前页面](#/docs/page-perception)。

**它复述的内容和你给的文档对不上。** 先把范围说小，让它只读你要的那部分再核对；仍对不上，把那一段直接复制给它更稳，见[把一份文档里的内容录进系统](#/docs/case-import-file)。

## 传不了图 / 用不了语音

**传图片被拒，或拍照按钮是灰的。** 两种常见原因：图片附件开关没开——到 设置 → 多模态 打开 **图片附件**；当前模型不接受图片——换能力标记里有 **可传图片** 的模型。见[附件、图片、语音与拍照](#/docs/attachments)、[选择模型](#/docs/models)。

**语音或拍照提示被浏览器拒绝。** 按提示到浏览器的站点权限里允许麦克风或摄像头再试。扩展版要先在它自动打开的那个普通标签页里授权一次，侧栏里才用得了，见[附件、图片、语音与拍照](#/docs/attachments)。

**传了长文本，回答却像没看完。** 文字超过 32K 字符会被截断。分段传，或先说清只要哪一部分，见[附件、图片、语音与拍照](#/docs/attachments)。

**PDF 发出去后模型报错。** 当前模型可能不接受文档输入：换模型，或把内容转成 Word、纯文本再发。

## 页面读不到 / 操作没生效

**它说看不到页面内容。** 多半是你所在的系统没开页面感知：到控制台 **页面技能** 页看感知状态是不是「未启用」，确实没开就联系提供这个系统的人。见[让助手读当前页面](#/docs/page-perception)。

**它说点了，页面却没反应；或工具调用显示「被策略拒绝」。** 那一步被安全策略拦住了，或你没有授权。点拒绝只让那一步失败、整轮运行继续；策略问题先看拒绝原因，确有需要联系提供这个系统的人调整。见[让助手操作页面](#/docs/page-actions)。

**它说找不到要操作的东西。** 页面一变，它记下的元素就失效了。让它重新读一次再试——它多数会自己这么做。见[让助手操作页面](#/docs/page-actions)。

## 技能相关的问题

**错误卡写「模型反复调用不存在的工具。请确认该技能真的带了它描述的那些脚本。」** 多半是技能和当前页面对不上，或技能缺文件。换个说法重试；仍不行，到控制台技能管理的「完整性与清单」页校验这个技能，见[技能管理](#/docs/console-skills)。

**错误卡写「有工具的参数结构无法发给当前模型。可在『设置 › 生成式 UI』中关闭生成式 UI，或更换模型。」** 照做，二选一：关掉生成式界面（回答退回文字与卡片），或换一个模型。见[设置](#/docs/console-settings)、[选择模型](#/docs/models)。

**装完了，对话里却调不到。** 到「完整性与清单」页看「依赖环」「依赖缺失」两节——列在那里的技能被排除出了技能目录，助手看不到。装上它声明的依赖，或解开绕成圈的依赖即可恢复，见[技能管理](#/docs/console-skills)。

**技能联网或取数被拒。** 到 设置 的 **沙箱与安全** 页：确认网络策略不是「全部拒绝」，把要访问的地址加进 **白名单**，用 **试跑 URL** 当场确认放行，再回对话重跑。见[设置](#/docs/console-settings)。

## 断网、弱网与多标签页

**生成到一半断网了。** 会出现错误卡（「请检查设置中的模型配置，或重试。」），已生成的那部分正文保留，不会被清空。网络恢复后直接重发同一条，不用刷新页面。

**弱网下回答很慢。** 慢是正常的：输出会变慢，但不中断。极端弱网下要么完成、要么给出明确的超时错误，不会无声地卡住；**停止** 按钮一直可点。

**生成中途关了标签页，或电脑睡了一觉。** 重新打开：会话不损坏，已生成的部分完整，未完成的那条保留半截或明确标为中断。停在表单类卡片上的运行，刷新后顶部有恢复横幅，点它接着来，见[提问、回答与打断](#/docs/chat-basics)。

**在另一个标签页看不到这边刚开的会话、刚装的技能。** 两个标签页共享同一份本机存储，刷新那个标签页就能看到；两边同时发消息也不会互相覆盖，各自的历史都完整。

## 这些不是故障

**历史会话里的卡片、按钮点不动。** 那是已保存的记录（「这是已保存的记录，其中的操作已不可用。」）。想重新操作就发新消息，见[会画画的回答：生成式界面](#/docs/generative-ui)。

**条目组好像少了几条。** 有「当前渲染档只显示重复组的第一项。」这行提示，就是显示限制，数据没丢，换一种呈现方式即可看全，见[会画画的回答：生成式界面](#/docs/generative-ui)。

**我只想微调，它却整份重做了一遍。** 固定模板的产物改不动，它换「现做的」重出了一版。想少跑一轮，第一句话里就把范围和要求说清，见[技能：让助手会干专业活](#/docs/skills-usage)。

**同样的需求，这次页数不一样。** 走的是「现做的」，页数由内容决定，不固定，见[技能：让助手会干专业活](#/docs/skills-usage)、[做一套幻灯片并放映](#/docs/case-slides)。

**它没处理完整个列表就收尾了。** 一轮最多同时开 32 页，撞上限了。把范围说小（前 20 行、只看一类），分两轮跑；它没法向你要更多配额，不会主动提这件事，见[跨标签页工作（仅扩展版）](#/docs/tabs)。

**刚看过的那一页忽然点不动了。** 那一页被关掉或跳走了，已不在工作集里。让它重新列一下现在能用的页面再继续，见[跨标签页工作（仅扩展版）](#/docs/tabs)。

**会话列表里出现「以下会话文件读不动，已跳过：…」。** 个别会话文件这次没读出来，被跳过了，其余会话不受影响。重新打开面板或刷新再看一次；反复出现，按下一节报问题，见[管理会话](#/docs/sessions)。

## 这里查不到怎么办

**先自己查。** 展开那次运行的 **运行流程** 卡片，点 **复制运行 ID**，到控制台 **运行记录** 里粘贴搜索，逐步回看它停在哪一步、哪次工具调用失败、失败原因是什么。见[运行记录](#/docs/console-runs)。

**要报问题，给提供这个系统的人发三样：**

1. **运行 ID**——排查问题最重要的线索，复制方法同上。注意：删除会话时它的运行记录会一并删除，趁早复制。
2. **你看到的现象**——错误卡上的原话、大概发生的时间。
3. **诊断文件**——控制台 设置 的 **关于与诊断** 页点 **导出**，版本、技能清单、运行配置都在里面，模型密钥会被剔除。

![诊断导出的位置：设置 › 关于与诊断 页的「导出」按钮](/docs-assets/faq/zh/S-faq-02-diagnostics-export.png)

版本号也在同一页——报障时第一句通常会被问到的就是它。
