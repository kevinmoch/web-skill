# 做一套幻灯片并放映

用一句话让助手把项目数据做成一套幻灯片：在新窗口里放映、方向键翻页、可导出 PDF。这一章把技能、开窗确认和打印导出串成一次完整任务。

## 开始之前

打开 [Demo](/demo)，确认页面右缘能看到助手入口即可，全程在对话里完成。

## 第一步：提出需求

这句话原样来自 Demo 欢迎页「试试这些示例」的快捷提示，点一下或直接发给助手：

```
把所有项目的交付质量做成一份幻灯片，在新窗口里放映，支持翻页和导出 PDF
```

它没限定范围、也没提分页要求，会走「现成的」幻灯片技能：固定八页，对三个演示项目横向综合分析，最快也最稳。从这句话到放映经过这些环节：

![幻灯片的产生与放映：需求 → 助手生成幻灯片 → 请求开窗 → 你同意 → 新窗口放映 → 翻页或导出 PDF；提出加减页则重新生成一版](/docs-assets/case-slides/zh/M-27.svg)

「你同意」是必经一环：你不点头，窗口不会开。

## 第二步：同意开窗

幻灯片做好后，消息里会出现一颗 **打开文档** 按钮。点它不会直接开窗——先弹出一张标题为 **请确认** 的卡片，原文是：

`技能「{skillName}」要把一份文档投到独立窗口打开，其中包含来自「{dataSource}」的数据。是否继续？`

卡里 `{skillName}` 是要开窗的技能名，`{dataSource}` 是片子里数据的来源。点 **确认** 窗口才会打开；点 **取消** 就不开——这一轮会带着「你没同意」的结果继续，助手会说明窗口没能打开，不会卡住，更不会把窗口悄悄开出来。

![开窗前的「请确认」卡，写明哪个技能要开窗、数据来自哪里](/docs-assets/case-slides/zh/S-case-slides-01-open-confirm.png)

开窗前必问，卡上写清是谁要开、数据从哪来。

## 第三步：放映与导出 PDF

新窗口打开后就是放映形态：

- 用键盘方向键翻页，左下角的页码显示第几页、共几页。
- 投屏时点「隐藏工具条」收起工具条，角落里留有小圆钮可恢复。
- 点窗口右上角的 **打印** 按钮：它会把每一页先排成一张纸再调起打印，在打印对话框里选「另存为 PDF」即可导出。深色幻灯片打印不会丢底色——深底不会印成白纸。
- 想退出就关掉这个窗口；对话还在，再点一次 **打开文档** 可重新放映。

![八页幻灯片的封面页在独立窗口中放映，左下角显示页码](/docs-assets/case-slides/zh/S-case-slides-02-deck-cover.png)

封面页：三个项目的健康分总览。示例运行结果，你的实际输出会有所不同。

![翻到下一页，左下角页码同步变化](/docs-assets/case-slides/zh/S-case-slides-03-page-turn.png)

方向键翻页，共八页。

![导出的 PDF，每页一张纸，深色底色保留](/docs-assets/case-slides/zh/S-case-slides-04-exported-pdf.png)

PDF 里的版式与底色和屏幕上看到的一致。

## 换个说法，页数由你定

幻灯片是「现成的 / 现做的」差别最明显的一类产物（产物就是一次运行生成的成品）。现成的 `agile-slide-deck` 页数、页序、内容全部写死，就是那八页；现做的 `authored-slides` 页数由内容决定，你指定讲什么、分几页，做完还能要求加减页。一句话取舍与判断逻辑见[技能：让助手会干专业活](#/docs/skills-usage)。三种说法对照：

- 「把所有项目的交付质量做成一份幻灯片」→ 固定八页，最快。
- 「就讲当前迭代，分三页：进展、风险、下一步」→ 现做的，按你说的分页。
- 「幻灯片做好了，在风险后面加一页缺陷明细」→ 现做的，重做一版。

注意第三条：对现成的片子提修改，助手不是在原件上微调，而是换用现做的技能重新取数、重新出一份。这不是它没听懂，是固定模板确实改不动。

![按「分三页」的要求生成的一版，页数与固定八页不同](/docs-assets/case-slides/zh/S-case-slides-05-authored-three-pages.png)

同一次会话里先笼统地要、再限定分页，两版的技能标记与页数都不同。示例运行结果，你的实际输出会有所不同。

## 网页版与扩展版的差别

两者一致：确认卡、放映、翻页、导出 PDF 都一样。差别只在取数范围：网页版只取当前系统的数据，扩展版能先读你打开的其他标签页再出片，跨站点汇总的幻灯片只有扩展版做得出（见[跨标签页工作（仅扩展版）](#/docs/tabs)）。

## 出问题了怎么办

**点了「打开文档」，窗口没出来。** 先看是不是在确认卡上点了 **取消**——不开窗正是它该有的反应，再点一次并确认即可。确认后仍没开窗，多半是浏览器把新窗口当成弹窗拦下了：允许这个站点的弹窗，再点一次。

**打印出来只有一页。** 你用的多半是浏览器自己的打印入口。关掉预览，改用文档窗口右上角的 **打印** 按钮，它会把每页排成一张纸再打印。

**提了修改，它却整份重做了一遍。** 正常现象：固定模板改不动，它换现做的重出了一版。想少跑一轮，在第一句话里就把「讲什么、分几页」说清楚。
