# 看 DWG 图纸：查看、量测与对比

不用装 CAD 软件，也不用把几十 MB 的图纸拷来拷去：让助手把 DWG 图纸在独立窗口里打开——看图层、量尺寸，还能把两份图纸叠在一起，按构件比出差异并导成 Excel。

## 你能做什么

- 三条路打开 DWG 图纸：把 .dwg 当附件拖进对话、点页面上的图纸链接；扩展版还能直接读浏览器下载列表。
- 用「视图 / 图层 / 属性」三个分页看图纸，像 CAD 查看器一样开关图层。
- 用量测工具栏量距离、区域、坐标，读数实时跟着指针走。
- 把两份图纸叠在一起看：染色区分、调换上下、拖拽对位。
- 框选一块区域按构件比差异，编号标在图上，可导成 Excel。

![M-34 叠加对比的两层关系：上层新图纸、下层旧图纸，两层各染一色，重叠处显出第三色，差异圆圈落在两层之间](/docs-assets/dwg-viewer/zh/M-34.svg)

两份图纸像两张透明纸叠在一起：各染一色，差异用编号圆圈标在图上。

## 打开一份图纸

三条通道，随图纸在哪：

- **把图纸拖进对话**：把 .dwg 当附件拖进对话，或点 **添加附件**，图纸按原件字节收下。
- **页面上的图纸链接**：页面上指向 .dwg 的链接，让它打开；链接指向别的网站时，先弹确认卡再取。
- **浏览器下载列表**：刚导出的图纸，直接说「打开我刚下载的那份图纸」。列清单与读文件各弹一次授权卡，与[让它看你刚下载的那个文件](#/docs/downloaded-files)同一套。

> **仅扩展版**：三条通道里的「浏览器下载列表」一条只有扩展版有；网页版用前两条即可。下载列表会把 .dwg 标成「不可读取」——那说的是抽不出文本，照样能填给它看。

无论哪条通道，**图纸的字节都不进入对话上下文**：图纸在查看器一侧解析，助手拿到的只是概要（多少实体、哪些图层），对话里只出现文件名与取件号——它是帮你把查看器打开，不是把图纸读进对话。

![DWG 图纸在查看器窗口中打开，标题栏显示文件名](/docs-assets/dwg-viewer/zh/S-dwg-01-open.png)

窗口标题就是文件名；开两份时两个名字并排，不会认错。

## 看懂查看器

打开后默认停在**模型空间**，「视图」分页里可切到各张图纸空间；滚轮缩放、拖动平移，「属性」分页里的 **适应窗口** 把整份图收回视野。**画不出的内容会如实写明数量**，例如「另有 N 个 ACIS 三维实体无法显示」——三维实体这一版画不出，但不会悄悄漏掉；填充太密时会提示你放大再看。

## 视图·图层·属性

三个分页仿 CAD 查看器：**视图** 分页里图纸空间在上、模型空间在下，点哪张看哪张（图纸里没有图纸空间布局时这个分页不出现，只剩 **图层** 与 **属性** 两个）；**图层** 分页是按当前视图过滤的图层表，逐层勾开关，顶部一个复选框全选或全不选；**属性** 分页是操作提示与如实声明——没画出的实体数、近似绘制的内容都写在这一页。

![「视图 / 图层 / 属性」三个分页同屏可见](/docs-assets/dwg-viewer/zh/S-dwg-02-panels.png)

图层表跟着当前视图走：模型空间可能有几百个图层，图纸空间只有图框几个。

## 量测

画面下方的工具栏是量测：**距离**（点两个点）、**区域**（逐点围出，回车或双击结束）、**坐标**（指哪读哪）、**角度**（点三个点）、**删除**（点掉一条已有量测）、**清除**（清掉当前层的全部量测）。

读数**实时**跟着指针走，坐标工具指到哪读到哪；读数是纯文本，可以选中复制。两条换算规则要记牢：

- **模型空间里量到的就是真实尺寸。** 图纸自带单位（多半是毫米），不需要校准；图纸没写单位时它会明说，读数只是图纸单位——想要真实长度，先在工具栏 **设置** 里校准。
- **图纸空间里量，读数按视口比例换算回真实尺寸**：两个点落在同一个视口内时，按该视口的比例（如 1:200）折算并标明；不在视口内时，它会标明这是纸面尺寸，而不是给你一个错的数。

![量测工具栏与距离量测的实时读数](/docs-assets/dwg-viewer/zh/S-dwg-03-measure.png)

量距离时，连线上的读数实时跟着指针走。

## 两份图纸叠加看

一次最多两份，多给了它会明说，不会悄悄丢掉第三份。开两份时，每份图纸一块面板、一层画布，两层平面叠放，并多出一块 **叠放** 面板：

- **选中层与换序**：点一层设为当前层，量测都落在当前层上；**换序** 调换两层的上下。
- **显隐与染色**：每层可单独隐藏。默认两层各染一色、重叠处自然显出第三色，哪根线属于哪份图一眼可辨；点 **染色** 切回图纸原色。
- **对位**：两份图原点不一致时，点 **对位** 后拖动画布即可，平移的是当前层而不是视野；拖歪了点 **归零**。

对好位之后，量测可以**跨层吸附**：在新图纸上落点，能吸到旧图纸的端点、中点、圆心。两份图纸单位不一致时它会明说：跨层量出来的数没有可比性。

![两份图纸叠加显示，两层染色区分，叠放面板在侧](/docs-assets/dwg-viewer/zh/S-dwg-04-overlay.png)

上层一色、下层一色，重叠处是第三色。

## 按构件比差异

叠好之后点 **对比差异**，画布上出现一个可拖动、可从边角缩放的选框——**只比框内**，框上实时显示两侧各有几个构件。结果以编号圆圈标在图上：

- **悬停圆圈看这一条的说明**：数量变了、位置挪了、属性改了、新增了、缺失了，逐条写清，形如「{块名} 挪了 {距离}」。
- 面板显示统计汇总：共差几处，数量、位置、属性、新增、缺失各几处。位置容差（默认 200 毫米）可调，改完立刻重算。
- **导出差异** 把编号、说明与汇总写成一个 Excel 文件（汇总与差异明细两张表），存进浏览器的下载目录，编号与图上圆圈一一对应。
- 对比期间关掉某个 CAD 图层，差异**当场按同一选框重算**；换视图或重新对位则作废，需重新对比。

比不了它也明说：两份图纸的命名体系对不上时不出表，框内没有可比构件时如实告诉你。

## 网页版与扩展版的差别

查看器本身两种形态一致：「视图 / 图层 / 属性」分页、量测、两份叠加、按构件比差异与导出 Excel，网页版与扩展版完全相同。差别只在打开通道：扩展版多一条「直接读浏览器下载列表里的图纸」；网页版把图纸拖进对话、或点页面上的图纸链接即可。

## 出问题了怎么办

- **图纸打不开。** 多半是文件损坏或版本太老。先确认是 .dwg——.dxf 不受支持；再换一份文件试。都不行，把文件名与现象发给提供这个系统的人。
- **打开了但画不全。** 先看「属性」分页的声明：有三维实体时会写明有多少个没显示；填充太密时放大即可看到。图面太乱时，先在「图层」分页关掉不需要的。
- **量出来的数不对。** 先看在哪种空间量的：模型空间是真实尺寸；图纸空间按视口比例换算，落在视口外量到的是纸面尺寸，读数上会标明。图纸没写单位时读数只是图纸单位——先校准一个基准段再量。
