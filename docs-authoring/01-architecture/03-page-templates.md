## 1. 功能类章节（第 4-16、19-23 章）

```markdown
# 让助手操作页面

助手不只能读页面，还能替你点按钮、填表单、跳转页面。
这类操作会真的改变页面内容，所以每一次都要先经过你同意。

## 你能做什么

- 让助手代你填写并提交表单
- 让助手跳转到某个页面或某条记录
- 在助手动手之前审核它要做什么，并决定允不允许
- 对信任的操作选择「记住」，之后不再逐次询问
- 随时撤销已经给出的授权

> **注意**：<边界或风险>

## <小节：授权卡上都有什么>

<表格或列表逐项说明卡片上的元素>

## 网页版与扩展版的差别

|              | 网页版               | 扩展版 |
| ------------ | -------------------- | ------ |
| 能操作的范围 | 仅助手所在的这个页面 | <差异> |

## 出问题了怎么办
```

## 6. 元信息

每篇 Markdown 顶部不写 frontmatter——章节的标题、slug、顺序由
`src/docs/manifest.ts` 统一管理，避免两处真相打架。
Markdown 正文第一行就是 `# 章标题`，且必须与 manifest 中的标题一致。
