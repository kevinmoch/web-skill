# 03 · 术语表

**这张表是强制的。** 文档正文里指代界面元素时，必须使用与界面完全一致的措辞——
读者是照着文档在界面上找东西的，术语对不上就是文档缺陷。

术语的**唯一权威来源是源码里的 i18n 字典**，不是本表、也不是你的记忆：

| 面                   | 权威文件                                                       |

| chatbot 全部界面文案 | `packages/chatbot/src/i18n.ts`（en / zh 两段，377 条）         |

## 1. 核心概念（需要向读者解释的）

| 中文       | English             | 面向用户的解释（可直接改写使用）                                                       |
| ---------- | ------------------- | -------------------------------------------------------------------------------------- |
| 助手       | Assistant           | 你在对话框里说话的对象。它能理解你的话，并调用技能和工具帮你干活。                     |
| 技能       | Skill               | 一份打包好的"做某件事的说明书 + 脚本"。装上之后助手就会干这件事，比如出周报、做大屏。  |
| 工具       | Tool                | 助手能执行的一个具体动作，比如"读取需求列表""跳转到某个页面"。工具由你所在的系统提供。 |
| 工具调用   | Tool call           | 助手为了回答你，实际执行了一次动作。对话里会显示调用了几次、每次是什么。               |
| 会话       | Session             | 一段独立的对话。不同会话之间上下文互不影响。                                           |
| 交互卡     | —（按类型分别命名） | 助手在对话里弹出的小卡片，向你要信息或要许可。共 6 种，见 §2。                         |
| 授权       | Authorization       | 助手在做有副作用的事之前必须先获得你的同意。                                           |
| 页面感知   | Page perception     | 助手读取你当前正在看的页面内容的能力。                                                 |
| 页面操作   | Page action         | 助手在页面上点击、填写、跳转的能力。                                                   |
| 沙箱       | Sandbox             | 技能脚本运行的隔离环境。跑在里面的代码碰不到你的页面和数据。                           |
| 控制台     | Console             | 管理技能、查看运行记录、调整设置的地方。                                               |
| 生成式界面 | Generative UI       | 助手的回答不只是文字，还能直接渲染成表格、图表、表单、看板。                           |
| 产物       | Artifacts           | 一次运行生成的文件，比如报告、幻灯片、大屏页面。可下载。                               |

**解释纪律**：上表右列的解释在**每章首次出现该词时给一次**，之后直接用词。
不要每章都重复解释，也不要一次都不解释。

## 2. 六种交互卡（措辞必须逐字一致）

源自 `packages/chatbot/src/i18n.ts` 的 `interaction.*` 键（62 条，是第二大文案域）：

| 卡片类型 | 中文标题     | English                | 何时出现                                        |
| -------- | ------------ | ---------------------- | ----------------------------------------------- |
| 提问     | 需要回答     | Answer needed          | 助手需要你补一句话才能继续                      |
| 确认     | 请确认       | Confirmation           | 需要你点头/摇头的是非题                         |
| 表单     | 需要补充信息 | Information needed     | 需要你填多个字段                                |
| 选择     | 选择一个选项 | Choose an option       | 需要你从若干项里选                              |
| 授权     | 需要授权     | Authorization required | 助手要做有副作用的操作                          |
| 选文件   | 需要一个文件 | File requested         | 助手需要你提供一个文件（按钮：选择文件 / 拒绝） |

这 6 种是**独立章节**的内容（见 02-chapters 第二部分），不要混为一谈。

## 4. 禁用词与替换

| 禁止出现                   | 换成                                                            |
| -------------------------- | --------------------------------------------------------------- |
| 宿主 / host                | 你所在的系统、这个网站                                          |
| 运行时 / runtime           | 助手                                                            |
| 注册 / 挂载 / 注入         | 提供、加入、装上                                                |
| 端点 / endpoint            | 连接（console 的连接页里保留"MCP 端点"这个界面原词）            |
| 实例 / 组件 / store        | 无（重写句子）                                                  |
| 调用链 / 数据流            | 步骤、流程                                                      |
| **扇出—汇聚 / fan-out**    | **逐项处理一个列表**                                            |
| **工作集容量 / 句柄**      | **它一次最多能开多少页 / 那一页**                               |
| **委派 / delegate**        | **它把这一步交给了另一个技能**（界面上的「已委派给…」保留原词） |
| **预授权 / preauthorized** | **不用问你就能做的**                                            |
| **候选 / candidate**       | **等审批的技能**（界面上的「候选 ID」保留原词）                 |
| **抽取 / extract**         | **从文件里读出文字**                                            |
| 一键 / 智能 / 强大 / 赋能  | 无（删掉形容词，直接说做了什么）                                |

「扇出—汇聚」是内部需求文档里的叫法，取材时会大量遇到
（`docs/0.16.0/`、`docs/0.17.0/` 整两个版本的主题）。
**它对用户毫无意义，全书禁止出现。** 对用户就叫「逐项处理一个列表」。

**「文档正文」是界面原词，必须保留**——
它是附件类型标签上真实显示的四个字（docx / xlsx 归这一类）。
解释它的时候可以说"Word、Excel 这类文档"，但**指界面元素时用原词**。

例外：console 界面上**真实显示**为"MCP 端点""WebMCP""页面技能"的地方，
必须用界面原词，否则读者找不到。判据仍是「界面上写的是什么」。

## 5. 两种形态的命名

全书统一，不得混用：

| 概念             | 统一叫法                 | English           |
| ---------------- | ------------------------ | ----------------- |
| 嵌在网站里的助手 | **网页版**               | Web version       |
| 浏览器扩展形态   | **扩展版**               | Extension version |
| 本站的示例系统   | **Demo**（Agile Studio） | Demo              |

禁止出现的变体：内嵌版、插件版、浏览器版、sidepanel 版、side panel 助手。
